拿一个输入走通方法

示意商品零售价 100，卖方成本估值 70，买方预算 80。数字仅用于解释，不是论文样本。

  1. 买卖双方看各自允许的信息：买方知道预算，卖方知道成本估值，双方围绕商品交替报价。
  2. 若最终同意 75，这笔模拟交易同时满足预算与成本约束；Judge 判接受并记录成交价。
  3. 若买方同意 90，虽然低于零售价，也超过预算；评测要记越预算，而不能只把“谈成”算作好结果。
  4. 若预算设为 60 而成本为 70，按约束本就没有可行成交价；拒绝可能是正确行为，强行成交反而有风险。

关键设计为什么需要

把收益指标与委托约束分开，才能区分“议价厉害”和“遵守用户边界”。论文观察风险，并非已给出能保证安全的交易系统。

术语就地解释

成本是论文中的模型估算值，不是实际采购账单；这里讨论模拟交易，非真实支付。

The Automated but Risky Game: Modeling and Benchmarking Agent-to-Agent Negotiations and Transactions in Consumer Markets

Shenzhe Zhu, Jiao Sun, Yi Nian, Tobin South, Alex Pentland, Jiaxin Pei · arXiv v4 · 2025-09-20

一句话读懂

让买方与卖方 LLM 在商品、预算和估算成本约束下自动多轮谈判；比较模型议价能力，并统计越预算、低于成本、溢价购买和谈判僵局等异常。

原图 Fig.1｜商品、双边 Agent 与裁判组成谈判闭环

买家看商品、零售价及预算；卖家看商品、零售价及批发成本估值。双方轮流报价，Judge 判断接受/拒绝/继续，Analyst 抽取价格变化。谈成则记为交易，拒绝或达到轮次上限则结束。原图 Fig.1 · PDF p.3 · §2

实验问题与商品数据

  • 问题一：不同模型替用户谈判时，成交价格和盈利表现是否不同？
  • 问题二：完全自动谈判会产生哪些消费端或商家端风险？
  • 构建 100 个真实消费商品样本：汽车、电子产品、房地产。零售价和商品特征来自公开资料；批发/成本价由 GPT-4o 根据商品信息估算，并提供给卖方 Agent。
  • 因此这是基于真实商品信息的模拟实验，不是真实买卖或真实市场成交。

来源：§1、§2.4，PDF pp.1–3；成本价估算方式见 Appendix C.2。

衡量议价能力与交易质量

指标含义
PRR · Price Reduction Rate(零售价−最终成交价)/零售价；买方越高越有利，卖方越低越能守价。
RP · Relative Profit卖方总利润相对最低利润基准的比例。
Profit Rate / Deal Rate成功交易的平均利润率 / 成交率；辅助观察利润与成交的取舍。
OBR / OWR成交价超买方预算的比例 / 成交价低于卖方成本的比例。
OPR / DLR买家在预算允许更低支出时仍高于零售价成交的比例 / 谈满 30 轮未决比例。

主要发现｜议价能力不对称

  • 模型差距明显：o3 在整体议价表现突出；GPT-4.1、o4-mini 紧随。GPT-3.5 整体较弱。作者发现更强模型通常能当买家压低价格、当卖家维持较高售价。
  • 卖方利润取决于成交与毛利平衡：多数模型总利润约为 GPT-3.5 的 9.6 倍；GPT-4.1 约 13.3 倍、DeepSeek-R1 约 12 倍。某些模型虽单笔利润率高，成交率低导致总利润较差。
  • 规模效应：Qwen2.5 0.5B–32B 对局中，较大版本在买卖两侧通常表现更好；模型能力指标与议价分数相关，其中 MMLU r=0.93、MATH r=0.87、GPQA r=0.81，参数量 r=0.53。

来源：§3.2–3.4、Fig.2–4，PDF pp.5–7。相关性不代表单一能力导致议价优势。

四类风险｜不只是“谈不下来”

  1. 违反预算/成本约束：买家越预算成交、卖家低于批发成本出售。Qwen2.5-7B 总体 OBR 11.76%、OWR 7.91%；GPT-3.5 分别 6.25%、5.75%。
  2. 过度支付：高预算买家容易透露预算，卖家据此锚定价格，买家可能高于零售价成交。
  3. 谈判僵局：Agent 在无进展时仍持续讨价还价，消耗轮次与 API 成本。
  4. 过早妥协：预算较高时买家更快接受“低于预算”的报价，议价压价反而减弱。

来源：§4.1、Fig.5–10，PDF pp.7–10。百分比按各模型论文所定义实验汇总率。

证据边界｜读结果时别越过模拟设置

  • 零售价和商品样本来自真实消费品；卖方 wholesale/cost 是模型估算值，不是内部采购账单或实际厂商报价。
  • 谈判双方都是 LLM Agent，设定通过系统提示实现；不是人类消费者与商家的实地试验。
  • 只覆盖 100 个商品中的随机子集、九种模型及指定协议；模型版本、提示和市场规则变化可能改变结果。
  • 论文明确承认仿真与真实谈判存在差距，未来需要真实平台和 human-in-the-loop 评估；RL 提示优化范围也有限。

来源：§2.4、§3.1、§6 Limitations，PDF pp.3–5、12。

最短复述

论文搭建了买卖双方都由 LLM 代理执行的消费者市场谈判模拟。模型能力差距会转化为议价和利润优势；与此同时，预算/成本约束违背、预算泄露后的过付、僵局与高预算下过早妥协都可能带来经济风险。结果是对一个结构化模拟市场的警示性证据，不能读成现实市场已经发生相同比例损失。
