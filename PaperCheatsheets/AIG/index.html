原日志 → 可编辑影响图 → 循边查原文 → agent/原始步骤

拿一个输入走通方法

检索 agent 声称已拿到原文，写作 agent 据此引用错误内容，核验 agent 又接受了这份引用。

  1. Builder 将若干原始步骤组合成检索、写作、核验动作节点，并在 step_refs 中保留原步骤编号。
  2. 写明哪项检索结果被写作继承，以及它在下游造成的具体错误 effect；不能仅因时间相邻就连边。
  3. Reader 先看核验输出及原日志，沿入边确认错误确实来自写作；再检查写作是否从检索继承同一错误。
  4. 若发现写作自己捏造了引文，而检索输出并没有该内容，不能继续把责任推给检索；最后用节点引用定位准确步骤。

关键设计为什么需要

图负责导航，原日志负责支持或否决某条 effect。没有这一步，Builder 的错误摘要也可能变成错误归因证据。

术语就地解释

step_refs：节点对应的原始日志步骤；effect：上游信息在下游造成的具体错误表现。

帮助理解的示例：为解释原文机制而简化，不是论文案例、实测结果或成功保证。方法依据：PDF p.4、PDF p.5。

原图裁切。左为可查日志和改图的 Builder，中间为图与审查循环，右为只能读取的 Reader。p.4 · Fig.3

任务与输入输出

  • 输入：原问题 q、失败最终回答、按步骤排列的 agent 输出日志 τ。默认推断时不访问正确答案。
  • 中间结果：G=(V,E)，每个节点引用 step_refs；继承边描述传递了什么及其下游错误 effect。
  • 输出：失败责任 agent â、精确原始步骤 t̂ 与原因。

p.4 · §3.1 · Fig.3

中文标签与阅读顺序

  • 读图顺序：Builder Agent（建图）→ critic–refiner（审查修正）→ Reader Agent（循图检查原日志）→ agent/step。
  • 类型词表固定为 task／orchestrator／agent／conclusion；自适应的是节点边界、抽象内容和边拓扑。

p.4 · §3.1 · Fig.3

方法：按执行顺序读

  1. 从空图开始：Builder 用 overview、read_step、range、search 等工具定向查看轨迹。
  2. 选择动作节点：决定哪些原始步骤合成一个动作，赋任务／协调／执行／结论角色，并写出相应摘要与输入输出。
  3. 标注影响：仅在下游继承了上游工作且与故障有关时，记录 inherited 和 effect；可跨非相邻步骤。
  4. 审查图：程序检查连通、无环、唯一根／汇；critic 对照原日志找语义问题，refiner 最小修改，最多三轮。
  5. 循图回溯：Reader 选候选节点；仅当原日志确认下游输出确有边所描述的错误，才把归因移到上游。
  6. 落回原步骤：没有入边能继续解释故障时，结合 step_refs 和原文确定 â、t̂ 并提交。

p.4 · §3.1 · Fig.3

前作不足 → 本文设计

相关做法的不足本文如何处理
平坦日志阅读：长距离传播被后续症状遮盖把动作与继承关系整理成可导航图，再按需打开原始步骤。
固定 IG 或 CHIEF 式预设切分／层级逐轨迹选择节点粒度和拓扑；节点类型仍有固定约束。
只读结构摘要可能继承建图幻觉critic/refiner 审查，Reader 再核对原日志中的具体 effect。

判断依据、差异与阅读边界

沿原文核对中间产物和接受条件；原图可点击放大。p.4 · §3.1 · Fig.3

判断依据与关键细节

  • 节点：task 是唯一根，conclusion 是唯一汇；orchestrator 表示调度，agent 表示执行动作。
  • agent 字段：summary、input、output、authorship、step_refs 等；可记录输出已违背自身收到的指令但仍向下游提交的锚点。
  • 边：继承关系说明来源与下游后果；时间相邻不自动证明影响。
  • 结构检查可程序化；语义真实性仍由模型结合日志判断，不能据“图无环”推断因果正确。

p.11 · 附录 A/B（续 p.12）

实验能说明什么

  • 作者结果：Opus-5 在 Algorithm-Generated、无正确答案访问时，精确步骤准确率 55.20%，agent 准确率 71.20%。
  • 边界：只在 Who&When 两个分区评价；没有节点／边金标准，新增建图与审查消耗更多 token；Hand-Crafted 的 agent 准确率未超过 CHIEF。

p.5 · §4.1（局限 p.9）

相对近邻的变化

  • 把“轨迹表示”与“读取方式”分开，使用原日志→结构日志→IG→AIG 的阶梯比较其贡献。
  • 在相同节点角色词表内，自适应确定动作边界及跨步继承关系。
  • 图作为调查接口：建图者可编辑，归因者只读；移动归因需要原日志证据。

p.4 · §3.1 · Fig.3

最值得记住

  • 最吸引人的点（整理者判断）：把故障图当成导航地图，每次沿边追责仍要回到原日志确认。
