首次进入点 → 干净检查点 → 清洗观察 → 重建后缀

拿一个输入走通方法

第 1–2 步是干净历史，第 3 步读到要遗忘的地址 z，第 4–5 步把它写进摘要与待执行计划；尚无不可恢复外部效果。

  1. 溯源定位 z 首次进入 τ=3，找到第 3 步之前最近的干净检查点。
  2. 保留检查点之前的 KV/状态，丢掉已受影响的后缀，并恢复相应环境状态。
  3. 清洗观察中的 z，按论文前提恢复其余反事实观察，从检查点后逐步重新执行。
  4. 新摘要与计划由清洗后的历史重新生成；不是拿旧摘要删掉地址字符串再接着用。

关键设计为什么需要

删除污染产物可能造成“该有的新计划却没生成”的状态缺口；重放既去影响，也补回从未见 z 时本应形成的状态。

术语就地解释

KV cache：模型已有 token 的注意力键值缓存；τ：目标首次进入步骤；保证依赖可重现观察和副作用前提。

输入 → 输出

  • 输入：受污染终态 R_T、待遗忘目标 z、来源图 G、检查点 C、记录的观察与可恢复环境。
  • 输出：与未观察 z 的参照运行态相同的重建状态；随机解码时改为评估未来行为分布一致性。

p.5 · Alg.1 / From Theorems to System

关键公式与标签

  • Rₜ=F(Rₜ₋₁,oₜ;θ)：模型与 scaffold 一起定义运行转移；状态包括 KV、工作记忆和未提交计划。
  • 精确重建最坏需 T−τ+1 次状态转移；T 为最终步，τ 为目标首次进入步。更早检查点会多重算干净段。
  • Taint closure＝受影响的可达闭包；Crop＝裁缓存；Sanitize＝删除目标、保留其他观察。

p.4 · Theorem 1 / Corollary 1

方法流程｜5 步

  1. 定位：通过目标来源节点找首次进入边界 τ，并计算派生物的污染闭包。
  2. 选点：取 τ 之前最近的干净检查点；它只保存 token 偏移、缓存句柄、提示清单和环境快照编号。
  3. 恢复：裁掉后缀 KV，加载环境快照；不携带原污染后缀的 KV 或模型派生状态。
  4. 清洗重放：观察中剔除 z、其余按反事实要求保留；读工具重跑或重放，后果型工具影子执行并按调用 ID 去重。
  5. 重建：依次重新执行转移，重新生成摘要、计划等派生物，接到保留前缀后形成新终态。

理论边界｜可删的是目标，必须重建的是影响

本文遗忘对象是可重建的非参数运行状态。前缀复用成立并不意味着原后缀里“看起来无关”的 KV 也能直接保留。p.5 · Alg.1 / From Theorems to System

前作不足 → 本文设计

前作或常见做法的不足本文对应设计
仅删除持久记忆记录，摘要、计划、缓存仍带目标影响。来源图定位首次进入点，跨 prompt、压缩记忆与 KV 重建后缀。
源字符串涂黑或要求“忘记”可能只压制显式复述。以“从未观察目标”的反事实行为为目标，并做诱导与无字符串行为审计。
全量重置丢掉确定相同的干净历史；IFC 主要控制未来流。用共享前缀拼接清洗重放，并可与 IFC 组合。

p.2 · Related Work

为什么“删干净”仍不够

  • 若只删掉目标及派生物却不重建，状态可能缺少未见目标时本应生成的摘要或计划。
  • 实验中的“闭包删除但不重放”可消除该测试中的泄漏，却仍有反事实动作差异；重放同时追求保留非目标效用。

p.7 · Ablations / Conclusion

具体变化｜作者方案

  • 问题定义：把遗忘从存储记录删除变成可重建运行态的反事实等价。
  • 恢复机制：前缀共享引理使 KV 裁剪成为检查点恢复；后缀原状态不复用。
  • 成本契约：在指定转移访问模型和保守污染假设下给出匹配的最坏重算下界；次数与自回归 token 数分开计算。

p.4 · Theorem 1 / Corollary 1

最吸引人的点

  • 整理者判断：把“何处开始重算”绑定到反事实首次分歧 τ，而非会话起点，给遗忘成本一个可解释边界。

解读 · p.4 · 整理者判断

作者实验与证据限制

  • 三类 agent suite、三种模型家族中，选择重放达到干净参照的审计水平；论文报告最多减少 9 倍重算 token。
  • 随机行为测试“未检出显著差异”不能当作统计等价证明；独立后目标内容的 prefill 优化还依赖更强归因 oracle。
