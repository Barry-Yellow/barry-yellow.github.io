暂存 → 提交检查 → 动作门 → 撤回/按类型处理后果

拿一个输入走通方法

工具返回“客户符合退款资格”，agent 准备把它写成共享信念，并可能据此退款。

  1. 先暂存该观察并记来源、权限和派生父项；在要求 committed-read 的读者看来，暂存内容还不可见。
  2. 提交检查证据、时间、冲突和父项稳定性，通过后才进入 committed 等相应状态；并非写入就可信。
  3. 退款这类不可逆调用再过动作门；检查未解决 tentative 及相应风险层所需支持，不满足则返回拒绝原因。
  4. 若资格信念被撤回：派生信念 revoked，摘要/副本 quarantined，可逆动作登记补偿，不可逆效果登记 leaked。

关键设计为什么需要

信念可见、可被相信、可支持动作、外部后果可撤销是四个不同问题。尤其动作门的存在式支持条件不证明退款每个输入都被充分验证。

术语就地解释

quarantined：隔离待重建；leaked：已发生不可逆效果的审计标记，不表示世界已被回滚。

输入 → 输出

  • 输入：agent 的记忆读写与撤回，以及领域工具调用；每条记录包含内容、来源权威、权限、派生父节点、类型、有效期和置信度。
  • 输出：提交或隔离的信念记录、允许或拒绝的动作，以及撤回后的级联修复/泄漏审计日志。

p.3 · §3.1–3.3

原图标签

  • TENTATIVE＝暂存；COMMITTED＝已提交；ACTION-SAFE＝可支持外部动作；QUARANTINED＝隔离待重建；REVOKED＝已撤销。
  • Cascade＝遍历派生 DAG；Typed repair＝按记录类型分派修复；Rollback log＝逐步审计。

p.4 · Fig.1

方法流程｜5 步

  1. 开事务：声明可信配置给出的风险层级，选隔离等级并捕获可见记录快照。p.3 · §3.1–3.3
  2. 暂存：新观察进入 tentative，同时登记 derived-from 边；已提交读以上的其他 agent 看不到它。p.3 · §3.1–3.3
  3. 提交：依次检查证据、时间有效性、语义冲突、依赖稳定性；竞争值在快照后已提交时，陈旧晚写先被拒绝，再谈来源权威。p.3 · §3.1–3.3
  4. 行动：不可逆工具先检查在途 tentative；外部风险事务还要求快照存在 action-safe 支持。失败返回结构化原因供解决后重试。p.3 · §3.1–3.3
  5. 撤回：abort 或 revoke 共用级联例程；逐类使后代失效并记录处理结果。p.4 · §3.4–3.5

级联修复｜协议保证与真实世界效果分开读

退款资格信念来自污染工具结果时，仅删除它还不够：由它生成的客户摘要、共享副本及已经调用的退款工具都需要登记处理。p.3 · §3.1–3.3

前作不足 → 本文设计

前作或常见做法的不足本文对应设计
Cordon 的事务边界主要容纳工具效果。把记忆当作受治理的信念对象，区分观察、提交、可行动与撤回。
一致性防护可阻止依赖失效，却不表达信念矛盾和权限洗白。提交时同时处理语义冲突、时间优先级、父记录撤回与权限继承。
TOKI 核心契约在写入时矛盾处理与审计。向行动时门控及撤回后的派生记忆/工具后果扩展。

p.2 · §2 / Table 1

类型分派具体做什么

  • 信念后代：置为 revoked。
  • 摘要、画像、索引与共享副本：置为 quarantined，等待由仍有效来源重建。
  • 工具动作：可逆者登记补偿；不可逆者登记 leaked，不宣称消除已发生的效果。

p.4 · §3.4–3.5

具体变化｜作者协议

  • 统一状态机：八种生命周期状态、五种读隔离、四种风险层级，把成熟度与可见性连接起来。
  • 组合接纳：先排除快照后的晚写，再按来源权威裁决重叠值；同权异源冲突隔离，派生权限不能放宽。
  • 撤回闭环：同一 DAG 连接提交、行动与级联审计，使 abort/revoke 两条入口共用处理规则。

p.3 · §3.1–3.3

最吸引人的点

  • 整理者判断：撤回并非统一删除；信念撤销、视图重建、工具补偿各有不同语义，这种分型比“回滚所有东西”更接近可执行协议。

解读 · p.4 · 整理者判断

作者验证证据

  • 对实现做属性检查与有界穷举：5,530,160 个规范状态未发现不变量违反。
  • LLM 场景使用确定性模拟工具；协议记账完整性不能等同真实退款或邮件已被撤销。

p.5 · §3.5 / §4

重要参考 · 已核验题名与官方链接

  • Cordon: Semantic Transactions for Tool-Using LLM Agents：围绕任务级工具效果建立暂存、验证与提交边界；MemTX 把事务对象扩展到可撤回信念及其派生物。
  • Verified Detection and Prevention of Concurrency Anomalies in Multi-Agent Large Language Model Systems：形式化共享状态并发异常并验证一致性层级；是 MemTX 隔离与级联验证的近邻工作。
  • TOKI: A Bitemporal Operator Algebra for Contradiction Resolution in LLM-Agent Persistent Memory：将记忆矛盾处理写成双时态写入算子，明确隔离与审计前提；MemTX 补入信念生命周期、权限继承与动作门。

p.9 · References（续 p.10）

必须看清的限制

  • I1 强式只要求快照至少有一个 action-safe 记录，并未证明当前动作的每个输入都来自它。LLM 主评估仅执行弱式门控。
  • 级联只覆盖已记录来源；补偿属于决策级义务，不是环境级重放。工具可逆性为静态标记。
  • 已读摘要、引言、§2–4、§5相关讨论与§6（pp.1–5、8）及 pp.9–10 参考。
