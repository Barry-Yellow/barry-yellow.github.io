轮级文本特征 → 关系聚合 → agent 池化 → 责任/类型预测

拿一个输入走通方法

A 把数量算错，B 引用该数继续作答，整条协作轨迹最终失败。这里要预测的是责任 agent 及错误类型，不是直接生成补丁。

  1. 把 A、B 每次发言各记为一轮节点，提取句向量、文本偏差与位置/长度特征。
  2. 连相邻轮的时间边和同一 agent 的轮间边；GNN 聚合这些关系，形成新的轮表示。
  3. 对 A 的所有轮分别求平均和最大值并拼接，对 B 也这样做，得到每个 agent 的分类输入。
  4. 分类头输出“正常＋各错误类型”的概率；错误类概率之和用于责任检测，通过阈值的 agent 再取最高分错误类。

关键设计为什么需要

mean 池化保留整体表现，max 池化保留局部强信号；输出仍是训练模型的预测，图边与高分本身都不证明 A 是唯一根因。

术语就地解释

GNN：沿图邻接聚合节点信息的神经网络；pooling：把多轮表示汇成一个 agent 表示。

任务与输入输出

  • 输入：已失败轨迹 T={(agentₜ,文本ₜ)}；训练还需要责任 agent 与预定义错误类型标签。
  • 中间结果：一轮一节点的图，节点特征矩阵 X，消息传递后的轮表示及 agent 池化表示。
  • 输出：被判故障的 agent 及其错误类型；任务目标是 agent／类型集合。

中文标签与阅读顺序

  • 读图顺序：Conversation Graph Construction（轮级图）→ GNN（邻居聚合）→ Prediction Head（分类）→ Agent Failure Attribution。
  • 术语：Temporal=相邻轮的双向边；Agent=同一 agent 的轮之间双向边；它们是构造关系，不等于经实验确认的因果边。

p.4 · §3.1–3.2（流程图 p.3）

方法：按执行顺序读

  1. 每轮提特征：本轨迹内 TF-IDF→截断 SVD，计算相邻偏差、自身一致性等；拼接位置／长度等统计和句向量。
  2. 固定规则建图：连相邻轮的双向时间边，以及所有同 agent 轮之间的双向边。
  3. 图消息传递：输入投影后堆叠带残差的 GNN 层，聚合文本与交互结构信号。
  4. 按 agent 池化：把同 agent 的轮表示分别求 mean 和 max，再拼接送入分类头，得到正常＋K 类错误 logits。
  5. 监督训练：二元“是否故障”损失与仅故障 agent 的错误分类损失加权相加；推断用验证集阈值或按分数排序。

相关做法的不足本文如何处理

判断依据、差异与阅读边界

沿原文核对中间产物和接受条件；原图可点击放大。p.4 · §3.1–3.2（流程图 p.3）

判断依据与关键细节

  • 轮特征：X=[偏差、统计、句向量]；偏差例子包括相邻文本差异、同 agent 一致性、与整段中心的偏离。
  • 聚合：zⱼ=[mean(hₜ), max(hₜ)]，t 属于 agent j；均值反映整体，最大值保留局部强信号（作用解释为整理者概括）。
  • 判定：故障概率为所有错误类 softmax 概率之和；选中 agent 后，预测其得分最高的错误类型。
  • TTA：以 agent／agent-error pair 的预测熵作无标签优化；论文借鉴 TENT 思路，并非新加人工 OOD 标签。
  • 注意：监督标签、预定义错误词表、句向量计算都仍需要资源；“近零推断成本”不能理解为整个系统无成本。

p.5 · §3.2–3.4

实验能说明什么

  • 作者结果：AEGIS-Bench 域内与多种 LLM 基线有竞争力；在 Who&When 域外仍有明显下降，TTA 提供有限改善。
  • 边界：固定图边体现时间与身份关联，未直接验证干预因果；不输出工作流补丁，也未建立根因修复成功率。

p.8 · §4.3（续 p.9）

相对近邻的变化

  • 把 AFA 组织为 agent 的正常／错误类型判别，而非生成长篇归因文本。
  • 组合语义句向量与轨迹内 TF-IDF 偏差／统计；图构造无需 LLM 推断边。
  • 训练拆为责任检测和故障类型两项；可在不同 GNN 后端上实现并做轻量 TTA。

p.4 · §3.1–3.2（流程图 p.3）

最值得记住

  • 最吸引人的点（整理者判断）：把“哪里出现异常”转成低成本的特征和聚合问题，给复杂 LLM 诊断提供了应认真比较的简单基线。
