Reflexion 不更新模型权重，而是把每次试错的轨迹和反馈写成自然语言经验，存入长期记忆，让 agent 在下一次试验中据此调整行动。

一轮尝试 → 任务评价 → 语言经验 → 记忆 → 下轮行动

拿一个输入走通方法

交互任务中 agent 找错了房间，跑完一轮仍未找到目标物品；Evaluator 给出失败信号。

  1. Actor 的动作和环境观察组成短期轨迹 τ，本轮结束后由任务专用 Evaluator 评价。
  2. Reflector 联合 τ 和反馈写经验，例如“上轮未检查目标常见位置；下轮先核对该房间”，而不只存“失败”二字。
  3. 经验加入容量受限的 episodic memory；下一轮 Actor 的提示可同时看到任务与这些文字经验。
  4. Actor 再采取行动；若反思不准确，下一轮仍可能失败。这个过程没有通过梯度更新模型参数。

关键设计为什么需要

奖励只指出好坏，语言反思尝试给出可执行方向；真正变化的是下轮上下文及行动选择，不是神经网络权重。

术语就地解释

Actor：行动者；Evaluator：评价器；Reflector：将轨迹反馈写成语言经验的模块。

问题与输入 / 输出

输入

单个语言 agent 与可交互环境；每次试验产出行动轨迹、环境观察，以及评估器给出的奖励/通过信号。

输出

跨试次更新的文本反思记忆 mem；Actor 把它与当前短期轨迹一起作为上下文，从而改变下一次行动。

方法执行顺序

1
启动 Actor / Evaluator / Reflector

Actor 根据当前状态产生动作；Evaluator 采用任务专用评分，例如环境任务完成信号、推理答案核验或代码测试结果。

2
运行一次完整试验

Actor 与环境交互，得到由动作与观察组成的轨迹 τₜ。当前轨迹就是短期记忆。

3
评估并生成语言经验

Evaluator 生成奖励 rₜ；Self-Reflection 联合轨迹和反馈，提炼可执行的改进建议，而非只保留一个分数。

4
把反思写入 episodic memory

将 srₜ 追加到 mem。论文实践中通常限制长期记忆容量（约 1–3 条），以控制上下文长度。

5
带着经验重试

下一轮 Actor 读取新旧经验，在相似情境中调整动作、计划或搜索策略；成功则停止，否则继续反思。

跨任务结果

论文摘要报告：相对基线，ALFWorld 提升 22%、HotPotQA 提升 20%、HumanEval 提升 11%。

代码示例

论文报告 HumanEval pass@1 为 91%；结果依赖其代码模型与测试评估配置。

机制结论

改进来自跨试次的文本经验累积，而非梯度更新模型参数。

适用边界

作者列出的限制：自然语言优化仍可能陷入局部最优；长期记忆采用容量有限的滑动窗口；代码任务的测试可能不准确，造成错误的通过/失败反馈。范围边界：原论文研究的是单个语言 agent 在交互环境中的学习，不是多智能体系统修复方法；可作为 MAS 中 agent 自我改进的基础机制或基线。

论文定位

单智能体的跨试次自我纠错/策略优化。它保留失败经验并影响后续尝试，但不针对多智能体的责任分配，也不执行系统级修复搜索。

一句话记忆：把每次失败压缩成下一次能用的文字经验；经验记忆就是它的“学习状态”。

核心思路

不更新权重，把一次失败和反馈压缩为下一次能执行的语言经验，并用有限记忆影响后续尝试。

创新点｜具体改了什么

  • 把文本经验作为可更新的学习状态，无需梯度更新。
  • Actor、Evaluator、Reflector 分工，连接反馈与下一次行动。
最吸引人的点 （整理者判断）

它把“学习”从改权重，变成了“记住一条下一次真能用上的经验”。

创新点为贡献归纳，不作未经全面核验的首次声明；亮点为整理者判断。
