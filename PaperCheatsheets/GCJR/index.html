一句话读懂

对单事件和图上可行的跨 agent 事件对逐一反事实重放，返回所有“成功且删去任一成员就失败”的集合。

p.2 · §II.A–C / Eqs.1–5

原论文 Figure 1 · PDF 第 2 页

原图裁切：从上到下：失败 DAG → 失败切片 → 单点/事件对候选 → 重放验证 → 最小修复族。图中仅同时改 eB、eC 才成功。p.2 · Fig.1

输入 → 输出

  • 输入：失败执行 DAG G；失败终点 o；可干预事件集合 C；每个事件配对的干净消息；重放成功判据与规模界 q≤2。
  • 输出：最小修复族，例如 {{u,v}}＝u 与 v 必须共同修改；{{u},{v}}＝两条可替代的单点修复。

p.2 · §II.A–C / Eqs.1–5

方法流程｜5 步

  1. 切片：只保留失败终点及其祖先中的可干预事件 Cₒ，剔除不能结构性影响失败的候选。
  2. 构造：测试全部单点；事件对须来自不同 agent、彼此不可达，并在失败切片内某个下游汇合节点相遇。
  3. 基准：先确认空干预仍失败，再用配对干净消息替换候选，重跑下游；各候选共用重放种子。
  4. 先单后双：保留成功单点；包含成功单点的事件对直接跳过，因为它不可能是包含意义下最小集。
  5. 返回：对剩余事件对重放，只保留成功者；请求结果缓存，输出所有保留集合组成的反链。

p.2 · §II.A–C / Eqs.1–5

图中词与关键判断

  • Failure Slice＝失败反向切片；Partial-Order-Aware Candidates＝考虑因果偏序的候选；Replay Verification＝重放验证。
  • hθ(S)=1 表示 r 次重放的成功比例达到 θ；最小性要求 S 成功且每个真子集失败，并非只比较集合大小。

前作不足 → 本文设计

前作或常见做法的不足本文对应设计
Who&When 一类点标签不能表示两个事件必须合改。用包含意义的最小集合族区分 Joint-AND 与 Alternative-OR。
固定 top-2 排名可能把可单改的点拼成非最小对。显式测单点，并剪掉含成功单点的事件对。
图盲枚举对全部候选做两两干预。反向失败切片 + 偏序/跨 agent/汇合约束缩减调用。

p.4 · §IV

一个必须保留的例子

  • 若 h({u})=0、h({v})=0、h({u,v})=1，则族为 {{u,v}}。
  • 若两个单点都成功，则族为 {{u},{v}}，不是 {{u,v}}；成功的双点集合也可能不是最小。

p.2 · §II.A–C / Eqs.1–5

具体变化｜相对已有归因/重放

  • 输出目标：由一个责任点、排名或选定修复，变成声明大小界内的完整最小成功族。
  • 搜索方法：用事件偏序与汇合关系筛掉域外事件对，而非仅依据日志相邻位置。
  • 保证范围：固定重放结果时，在声明候选域 Dɢ 中精确；只有真实最小族全部在该域中，才恢复完整有界族。

p.2 · §II.A–C / Eqs.1–5

最吸引人的点

  • 整理者判断：{{u,v}} 和 {{u},{v}} 的区别把“必须一起改”与“有替代方案”直接编码成输出，便于下一步修复决策。

解读 · p.2 · 整理者判断

作者实验说明了什么

  • 90 个域内受控 DAG 上族精确匹配 1.000，平均重放从 56.3 降至 25.3；24 个算术代理样例也与穷举族一致。
  • 这支持给定域和干净替代后端下的搜索正确性与节省，不证明开放任务能自动发现/生成修复。
