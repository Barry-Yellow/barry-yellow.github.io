把失败轨迹中每一步的隐藏表示放入谱参考空间打分，再用模型注意力估计步骤依赖，把后续异常证据回传给可能的上游错误源，选分数最高的一步。

表示谱参考 → 基础异常分 → 下游分数回传 → 步骤排序

拿一个输入走通方法

早期步骤 a 引入错误数字，后续 b、c 沿用它；c 的报错文字最显眼，却可能只是下游症状。

  1. 用一组无步骤标签的失败参考轨迹提取表示并做 SVD；验证集选出用于评分的谱带，不是随意取最大奇异值。
  2. 对待测的 a、b、c 计算在该谱带上的平均投影能量 q，得到基础分 S=1/(q+ε)；分越高越异常。
  3. 从冻结模型注意力估计 b、c 对更早步骤的软依赖；把后续基础异常分的加权平均传给可能的上游。
  4. 用 Ŝᵢ=Sᵢ+γBᵢ 重排，再输出最高分步骤及其 agent；不保证这个例子中 a 一定能超过 c。

关键设计为什么需要

回传试图缓解“症状更显眼”的偏差。注意力只是依赖代理；γ 调节回传影响，超参数选择仍使用验证集步骤标签。

术语就地解释

SVD：把表示矩阵分解为正交方向；谱带：选定的一组连续方向；γ：回传强度。

阅读顺序：① 未标注失败轨迹形成参考表示矩阵 R；② 选定奇异向量带，给各步骤基础异常分；③ 从冻结模型注意力构造有向软依赖，将后续异常分回传；④ 取重评分最高步骤，并映射到负责 Agent。原图 Fig.2 · PDF p.4 · §3

问题设定｜标签只在轨迹层面可得

  • 输入：任务描述 x、失败轨迹 τ=(s₁…sT)，以及一组已知“失败”但无步骤标注的参考轨迹。
  • 目标：找出最早引入最终失败的决定性错误步骤 t*；负责 Agent 是该步所属 Agent。
  • 困难：错误之后的重试、错误提示等下游症状，可能比源头更显眼，独立逐步评分容易定位过晚（downstream contamination）。

来源：§2，PDF pp.2–3。测试轨迹的金标用于评估；验证集金标用于选超参数。

阶段一｜谱空间给出基础异常分

冻结 LLM 为参考集和待测轨迹提取步骤表示；把参考表示按行堆叠为 R，做紧凑 SVD：R=UΣVᵀ。在验证集选一段连续奇异向量带 C。

qC(vt) = meanc∈C ⟨vt, V:,c⟩²　　S(st) = 1 / (qC(vt) + ε)

直觉：参考谱空间由常见普通步骤主导；落在所选方向投影能量较低的步骤，得到更高异常分。不是简单取最大或最小奇异值，而是验证集选择谱带。

来源：§3.1、Eq.2–4，PDF pp.4–5；投影异常解释是作者方法假设。

实验怎么做｜解释“无步骤训练标签”

  • 数据：Who&When（算法生成 126、人工构造 58）、Correct-Error（2,226）、Trace Elephant（Captain 85、Magentic 91）。
  • 划分：按轨迹 30% 参考 / 20% 验证 / 50% 测试。参考集隐藏步骤标签；验证集标签用于选表示层、谱带、注意力层带与 γ。
  • 骨干：Qwen3.5-9B、DeepSeek-R1-Distill-Llama-8B；另测更大骨干、跨子集迁移和合成参考轨迹。
  • 对照：提示式裁判、监督分类/诊断，以及只用成功轨迹的一类方法。

来源：§4.1–4.2、Table 1、Fig.4，PDF pp.6–8。

消融告诉我们什么

  • 作者报告谱评分优于七种替代分数；WW-AG 上谱分 39.15，最强替代仅 18.52（分析表口径）。
  • 注意力回传优于均匀聚合和位置偏置：WW-AG 47.62，对比最强替代 40.74。
  • 敏感性分析中 γ=0.6 附近表现最好；最佳表示层偏后，最佳注意力层带偏早。

来源：§4.3、Table 3–4、Fig.5，PDF p.9。个别消融结果的骨干/数据子集口径见原文表注。

读者应保留的边界

  • “无步骤标签”指参考集不提供步骤金标、模型不靠步骤标签训练；超参数选择仍使用验证集步骤标签。
  • 注意力权重被当作依赖代理；对“注意力是否代表因果依赖”的直接验证不足，性能消融不能完全回答这个问题。
  • 只在论文给出的标注基准和模型设置上评估；它是在已知失败轨迹中的事后归因，不等于在线预警或普适根因证明。
  • 本速读未复现实验，也未核查代码运行。

前三点为论文协议/方法与谨慎解读；原文 §2–4、Conclusion，PDF pp.3–11。

与前一篇 LONG RCA BENCH 的关系

按题名与本篇问题设定作快速定位：LONG RCA BENCH 聚焦长时程 Agent 失败中的“责任角色 + 根因”诊断；SOAP 聚焦无步骤标签失败轨迹中的“决定性错误步骤”排序，并把步骤映射回其 Agent。两者相关，但标签粒度和方法目标不同。

此处只作题名/任务层面的定位；未在本次逐节核读 LONG RCA BENCH，不能据此判定方法优劣或完整重叠。

最短复述

SOAP 利用“失败轨迹里多数步骤仍属普通行为”这一稀疏异常假设，在无步骤标签参考集上建立表示谱空间；然后用冻结 LLM 的注意力构造步骤依赖，让后续失败症状把分数回传到可能的早期源头。论文在五个子集、两种开源骨干上报告了较强的步骤定位准确率。核心未决点是注意力依赖代理的因果有效性。

核心思路

SOAP 用无步骤标签的失败轨迹建立表示谱参考，再将下游异常信号沿注意力软依赖回传，给更早的错误源重新排序。

已有做法与具体不足本文的对应设计
提示式归因推理成本高，监督归因需要步骤标签冻结模型，在失败参考轨迹的表示谱上打分。
只学成功行为的参考集不直接利用失败数据利用“失败轨迹中多数步骤仍是普通行为”的稀疏异常假设。
独立评分容易选中显眼的末端症状把后续异常沿软依赖回传到更早步骤。

创新点｜具体改了什么

  • 无步骤标注失败参考集上的谱评分。
  • 将异常检测与依赖回传组合，针对下游污染纠偏。

用末端失败症状给上游“追责”，而不是把最显眼的报错直接判成根因。
