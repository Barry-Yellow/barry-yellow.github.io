# 深度报告框架

深度报告的任务，是建立一个可验证的长期投资逻辑。它要回答为什么现在研究、核心变化是什么、市场错在哪里、利润怎么算、估值怎么算，以及什么情况会错。

## 标准流程

1. 选题：判断行业或公司是否有研究价值，优先选择空间大、变化大、预期差大、争议大的对象。
2. 提问题：报告必须回答一个主问题，例如“这家公司能否从周期股变成长逻辑？”或“行业拐点是否成立？”
3. 搭框架：先写目录和核心结论，再填证据，避免先堆资料。
4. 收集资料：公司公告、财报、招股书、行业数据、竞品资料、专家访谈、产业链价格、政策文件。
5. 产业分析：需求、供给、价格、成本、库存、产能、技术、渠道、竞争格局。
6. 公司分析：商业模式、产品、客户、成本、壁垒、管理层、资本开支、现金流。
7. 财务建模：拆收入、毛利率、费用率、利润、现金流、资本开支、营运资本和资产负债表。
8. 估值定价：选择 PE、PB、PS、EV/EBITDA、DCF、SOTP、NAV 等方法。
9. 形成结论：给出盈利预测、目标价、评级、上涨空间、催化剂和风险点。
10. 复核推演：检查假设是否合理，估值是否双重计算，风险是否足以推翻结论。

## 公司深度报告框架

| 模块 | 需要回答的问题 |
|------|----------------|
| 投资摘要 | 一句话观点是什么，推荐逻辑、盈利预测、目标价、风险是什么 |
| 公司概况 | 公司历史、股权结构、业务结构、产品结构、收入利润来源是什么 |
| 行业空间 | 市场规模、增速、渗透率、生命周期和天花板在哪里 |
| 商业模式 | 卖什么、卖给谁、怎么赚钱、议价权在哪里、现金流质量如何 |
| 竞争格局 | CR3/CR5、市占率、进入壁垒、替代品、上下游关系如何 |
| 成长逻辑 | 量增、价升、份额提升、品类扩张、区域扩张、海外扩张、效率提升是否成立 |
| 盈利能力 | 毛利率、净利率、ROE、ROIC、费用率、资产周转率如何变化 |
| 财务质量 | 应收账款、存货、经营现金流、资本开支、负债率、商誉、减值风险是否异常 |
| 管理层与治理 | 战略稳定性、激励机制、关联交易、分红、回购、融资历史如何 |
| 估值与目标价 | 相对估值、绝对估值、可比公司、历史估值、情景分析如何支撑目标价 |
| 风险与催化 | 业绩兑现、政策、价格、成本、竞争、汇率、技术路线、订单风险是什么 |

## 行业深度报告框架

| 模块 | 需要回答的问题 |
|------|----------------|
| 行业定义 | 产业链边界、上下游、主要产品、盈利环节是什么 |
| 需求端 | 终端场景、客户结构、渗透率、替代逻辑、周期属性如何 |
| 供给端 | 产能、产量、库存、技术路线、进入壁垒、扩产周期如何 |
| 价格机制 | 谁定价，价格跟什么变量走，成本传导能力如何 |
| 利润分配 | 产业链哪一环节赚钱，利润为什么在那里 |
| 竞争格局 | 集中度、龙头优势、区域差异、海外竞争如何 |
| 政策影响 | 补贴、监管、准入、环保、医保、军采、关税如何影响行业 |
| 周期位置 | 行业处于景气上行、见顶、下行、出清还是复苏 |
| 投资主线 | 买龙头、买弹性、买拐点、买低估、买技术变化还是买国产替代 |
| 标的筛选 | 市占率、成本优势、技术壁垒、订单、利润弹性、估值安全边际如何 |

## 深度报告的质量标准

优秀深度报告不是资料越多越好，而是证据链越清楚越好。核心质量标准包括：

- 主问题明确：全文围绕一个可交易判断展开。
- 假设可验证：关键变量能在后续跟踪中被数据验证。
- 模型可计算：结论能落到收入、利润、现金流、估值和目标价。
- 风险可推翻：明确什么条件会证明判断错误。
- 观点有预期差：说明市场原本怎么看，自己为什么不同。

## 可验证研究假设

深度报告不能只写“行业空间大”“公司竞争力强”，而要把观点拆成可验证假设。

| 假设类型 | 典型表述 | 需要的数据 | 验证方式 |
|----------|----------|------------|----------|
| 需求假设 | 行业需求未来 3 年 CAGR 为 15% | 终端销量、客户资本开支、渗透率、订单、渠道调研 | 实际销量和订单是否连续 2-3 个季度高于模型假设 |
| 供给假设 | 供给扩张慢于需求，行业维持紧平衡 | 产能、开工率、库存、扩产周期、竞争对手公告 | 新增产能是否低于需求增量，库存是否未显著累积 |
| 价格假设 | 产品价格维持稳定或缓慢下行 | 高频价格、合同价格、招标价格、竞品价格 | ASP 跌幅是否低于模型假设，毛利率是否稳定 |
| 份额假设 | 公司市占率从 10% 提升到 15% | 公司销量、行业总量、客户结构、订单份额 | 公司增速是否持续高于行业增速 |
| 利润率假设 | 规模效应推动毛利率提升 2pct | 单位成本、产能利用率、产品结构、原材料价格 | 毛利率改善是否来自主营业务，而非一次性因素 |
| 估值假设 | 公司应享受高于行业的估值溢价 | 同业 PE/PB/EV、成长性、ROE、现金流、治理质量 | 溢价是否能被增速、确定性和回报率解释 |

研究假设必须满足三个条件：有数据来源、能定量测算、能被后续证伪。

## 数据支撑清单

深度报告至少要建立四类数据表。

| 数据表 | 核心字段 | 作用 |
|--------|----------|------|
| 行业景气表 | 需求量、价格、库存、开工率、产能、订单、政策事件 | 判断行业周期位置和景气拐点 |
| 公司经营表 | 分业务收入、销量、ASP、毛利率、客户结构、产能利用率 | 判断公司增长质量和份额变化 |
| 财务质量表 | 应收、存货、经营现金流、资本开支、负债率、ROE、ROIC | 验证利润是否真实、增长是否健康 |
| 估值比较表 | 可比公司 PE/PB/PS/EV、增速、ROE、利润率、现金流 | 判断目标估值是否合理 |

数据频率要匹配研究问题。价格、库存、订单适合月度或周度跟踪；财务数据通常按季度更新；产能、技术路线和竞争格局按重大事件更新。

## 基础数学模型

公司深度报告的基本模型可以从收入、利润和估值三层展开。

收入拆分：

$$
Revenue_t = Volume_t \times ASP_t
$$

份额驱动收入：

$$
Revenue_t = MarketSize_t \times MarketShare_t \times ASPIndex_t
$$

利润拆分：

$$
NetProfit_t = Revenue_t \times GrossMargin_t - Opex_t - Tax_t + NonOperating_t
$$

EPS 和目标价：

$$
EPS_t = \frac{NetProfit_t}{Shares_t}
$$

$$
TargetPrice = EPS_{t+1} \times TargetPE
$$

深度报告应说明每个变量的来源和假设，而不是只给最后的目标价。

## 数据变化对应的结论

研究中最重要的是知道什么数据会改变结论。

| 观察到的数据 | 常见结论 | 需要警惕的反例 |
|--------------|----------|----------------|
| 公司收入增速连续高于行业增速 | 份额提升可能成立 | 是否来自低价抢量或并购并表 |
| 毛利率上升且库存未增加 | 产品竞争力或成本优势增强 | 是否来自原材料短期下跌或会计口径变化 |
| 经营现金流长期低于净利润 | 利润质量偏弱 | 是否由正常扩张期营运资本占用导致 |
| 应收账款增速显著高于收入 | 回款压力或收入质量风险上升 | 是否因客户结构切换到大客户导致账期拉长 |
| 存货增速高于收入且价格下行 | 需求走弱或减值风险上升 | 是否为订单备货或新产品爬坡 |
| 资本开支大幅增加但 ROIC 下行 | 扩张效率下降 | 是否处于产能投放前期，收益滞后体现 |
| 估值提升但盈利预测未上修 | 可能由风险偏好驱动，持续性较弱 | 是否有长期商业模式重估 |

## 置信度评分

深度报告结论要给置信度，而不是只给“买入/推荐”。可以从五个维度打分，每项 0-5 分。

| 维度 | 低分表现 | 高分表现 |
|------|----------|----------|
| 数据可靠性 | 主要来自传闻、单一专家或不可复核数据 | 来自公告、财报、海关、协会、价格数据库等多源交叉验证 |
| 假设稳定性 | 关键变量波动大，预测高度依赖单一假设 | 需求、价格、成本和份额假设均有历史或产业证据支持 |
| 模型敏感性 | 目标价对单一变量极度敏感 | 多数关键变量变化后结论仍成立 |
| 预期差强度 | 市场已有充分定价 | 市场一致预期明显低估核心变量 |
| 证伪清晰度 | 不知道什么情况算错 | 有明确数据阈值和验证时间窗口 |

总分可以转化为结论置信度：20 分以上为高置信度，15-20 分为中高置信度，10-15 分为中等置信度，10 分以下不应给强推荐。

## 结论验证模板

深度报告发布后，要把核心假设转成跟踪表。

| 核心假设 | 当前假设值 | 验证数据 | 验证频率 | 强化条件 | 证伪条件 |
|----------|------------|----------|----------|----------|----------|
| 行业需求增长 | 未来 3 年 CAGR 15% | 终端销量、订单、客户资本开支 | 月度/季度 | 连续两个季度高于模型 | 连续两个季度低于模型 5pct 以上 |
| 公司份额提升 | 市占率提升 5pct | 公司销量、行业总量、客户份额 | 季度 | 公司增速高于行业 10pct | 公司增速低于行业或大客户流失 |
| 毛利率改善 | 毛利率提升 2pct | 毛利率、原材料价格、产品结构 | 季度 | 毛利率持续改善且现金流同步 | 毛利率下滑且库存上升 |
| 估值溢价 | 高于行业 20% PE | 可比公司估值、盈利上修、ROE | 月度/季度 | 盈利上修且估值溢价稳定 | 盈利下修但估值仍高位 |
