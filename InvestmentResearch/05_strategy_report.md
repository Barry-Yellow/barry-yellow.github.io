# 策略报告框架

策略报告解决“市场、行业、主题怎么配”。它的核心不是宏观叙述，而是把宏观环境、市场风格和行业比较转化为配置建议。

## 标准结构

1. 宏观判断：经济增长、通胀、政策、利率、信用、汇率、海外环境。
2. 市场判断：估值水平、盈利周期、流动性、风险偏好、资金结构。
3. 风格判断：成长/价值、大盘/小盘、高股息/科技、周期/消费。
4. 行业比较：景气度、估值、拥挤度、盈利上修、政策催化。
5. 主题投资：AI、中特估、出海、国产替代、高股息、低空经济等。
6. 组合建议：超配、标配、低配行业，推荐标的池，风险提示。

## 宏观到配置的传导链条

```text
增长 -> 通胀 -> 政策 -> 利率/信用 -> 盈利/估值 -> 风格 -> 行业 -> 标的
```

宏观判断只有落到资产价格才有投资意义。例如利率下行可能提升成长股估值，信用扩张可能改善周期行业盈利，风险偏好回升可能推动小盘成长风格。

## 行业比较维度

| 维度 | 解释 |
|------|------|
| 景气度 | 需求、价格、订单、库存、产能利用率是否改善 |
| 估值 | 当前估值处于历史分位和同业比较的什么位置 |
| 拥挤度 | 机构持仓、成交占比、资金流入是否过热 |
| 盈利上修 | 市场一致预期是否上调，业绩是否超预期 |
| 政策催化 | 政策边际变化是否带来盈利或估值重估 |
| 风险暴露 | 利率、汇率、大宗商品、海外需求、监管变化的影响 |

## 风格判断

策略报告常见风格判断包括：

- 成长 vs 价值：取决于利率、盈利增速、风险偏好和产业趋势。
- 大盘 vs 小盘：取决于流动性、机构偏好、盈利确定性和监管环境。
- 高股息 vs 科技：取决于风险偏好、利率中枢和盈利确定性。
- 周期 vs 消费：取决于经济周期、库存周期、价格周期和居民消费能力。

## 组合建议

策略报告最终必须给出配置动作：

- 超配行业：景气改善、盈利上修、估值合理、风险收益比高。
- 标配行业：基本面稳定，但缺少明显预期差或催化。
- 低配行业：景气下行、估值透支、拥挤度过高或风险暴露较大。
- 推荐标的池：说明每个标的的推荐逻辑、催化剂和风险点。

## 常见错误

- 只有宏观判断，没有行业和组合建议。
- 只有主题叙事，没有盈利测算和估值约束。
- 只看景气度，不看估值和拥挤度。
- 只讲上涨逻辑，不讲什么情况下切换风格或止损。

## 策略研究数据框架

策略报告至少需要四组数据共同支撑。

| 数据组 | 核心指标 | 用途 |
|--------|----------|------|
| 宏观流动性 | GDP、PMI、CPI、PPI、社融、M2、利率、汇率、信用利差 | 判断经济周期、政策方向和估值环境 |
| 盈利周期 | 全市场 EPS、一致预期、盈利上修比例、ROE、毛利率 | 判断市场上涨是否有盈利支撑 |
| 估值与风险偏好 | PE/PB 分位数、ERP、股债收益差、成交额、换手率 | 判断估值性价比和风险偏好 |
| 资金与拥挤度 | 北向/ETF/公募仓位、行业成交占比、融资余额、持仓集中度 | 判断交易结构和反转风险 |

## 股债性价比模型

策略报告常用股权风险溢价 ERP 判断市场吸引力：

$$
ERP = \frac{1}{PE} - R_f
$$

其中 $R_f$ 可用 10 年期国债收益率。一般而言，ERP 越高，权益资产相对债券越便宜；ERP 越低，市场隐含预期越乐观。

结论判断：

- ERP 处于历史高分位：市场风险补偿较高，适合寻找估值修复机会。
- ERP 处于历史低分位：市场风险补偿不足，需要盈利高增长支撑。
- ERP 上行但盈利下修：可能是市场下跌驱动，不应简单看作买点。

## 行业配置打分模型

行业比较可以用多因子评分，而不是纯主观排序。

$$
Score_i = w_1 Growth_i + w_2 Revision_i + w_3 Valuation_i + w_4 Momentum_i - w_5 Crowding_i - w_6 Risk_i
$$

| 因子 | 指标例子 | 高分含义 |
|------|----------|----------|
| Growth | 收入增速、利润增速、景气指标改善 | 基本面趋势向上 |
| Revision | 一致预期 EPS 上修比例、业绩预告超预期比例 | 市场盈利预期改善 |
| Valuation | PE/PB 历史分位倒数、PEG、股息率 | 估值仍有安全边际 |
| Momentum | 相对收益、成交活跃度、趋势强度 | 市场开始验证逻辑 |
| Crowding | 基金超配比例、成交占比、换手率 | 过高时扣分，防止交易过热 |
| Risk | 政策、汇率、商品价格、海外需求、监管风险 | 风险越高扣分越多 |

模型不是替代判断，而是迫使研究员解释为什么超配某行业。

## 数据变化对应的配置结论

| 数据组合 | 策略含义 | 配置倾向 |
|----------|----------|----------|
| 利率下行 + 盈利稳定 + 风险偏好回升 | 估值扩张环境较好 | 成长、科技、高久期资产 |
| 社融改善 + PMI 回升 + PPI 企稳 | 经济修复和盈利上行 | 顺周期、制造、金融地产链 |
| 利率高位 + 盈利下修 + 风险偏好低 | 防御需求提升 | 高股息、公用事业、必选消费 |
| 行业盈利上修 + 估值低位 + 拥挤度低 | 性价比较高 | 超配该行业 |
| 行业涨幅大 + 盈利未上修 + 拥挤度高 | 交易过热 | 降低配置或等待回调 |

## 策略结论验证

策略报告要设置验证窗口。年度策略至少季度复盘，月度策略至少月度复盘。

| 策略判断 | 验证数据 | 强化信号 | 证伪信号 |
|----------|----------|----------|----------|
| 成长风格占优 | 利率、成长板块 EPS、相对收益 | 利率下行且成长 EPS 上修 | 利率上行且盈利下修 |
| 高股息占优 | 利率、股息率、风险偏好、盈利稳定性 | 风险偏好下降且股息率优势扩大 | 风险偏好回升且周期盈利改善 |
| 周期行业修复 | PMI、PPI、库存、商品价格、订单 | 价格和订单同步改善 | 库存上升但需求未改善 |
| 小盘风格占优 | 流动性、成交额、风险偏好、监管环境 | 成交活跃且小盘盈利扩散 | 流动性收缩或监管收紧 |
