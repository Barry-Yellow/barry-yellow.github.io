# 投研方法论学习

投研不是资料整理，而是用证据证明一个可交易的判断。本板块整理投资研究部门的工作流、报告生产框架、基本面分析、盈利预测、估值目标价和收益来源判断，目标是把分散信息转化为可验证、可计算、可跟踪的投资结论。

## 核心问题

一篇合格研报至少要回答以下问题：

- 为什么现在研究？
- 核心变化是什么？
- 市场错在哪里？
- 利润怎么算？
- 估值怎么算？
- 能赚多少钱？
- 什么情况会证明判断错误？

## 一条主线

投研工作的主线可以压缩为：

```text
选题价值 -> 核心问题 -> 证据链 -> 盈利预测 -> 估值目标价 -> 预期收益 -> 风险验证 -> 跟踪复盘
```

研究员的任务不是证明公司“好不好”，而是判断当前价格是否已经充分反映了基本面、预期变化和风险。
