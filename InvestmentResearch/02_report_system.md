# 投研部门工作流与研报生产框架

投研不是资料整理，而是用证据证明一个可交易的判断。研报必须把宏观、行业、公司、财务、估值和市场预期转化为投资结论，最终回答：买不买、什么时候买、买多少、预期收益多少、风险在哪里、什么情况证明判断错了。

## 投研部门做什么

| 项目 | 内容 |
|------|------|
| 核心任务 | 把宏观、行业、公司、财务、估值、市场预期转化成投资判断 |
| 最终问题 | 买不买、什么时候买、买多少、预期收益多少、风险在哪里、什么情况证明判断错了 |
| 主要产出 | 深度报告、点评报告、跟踪报告、策略报告、数据库、盈利预测模型、估值模型、路演材料、晨会纪要、组合建议 |
| 服务对象 | 基金经理、投资经理、交易员、销售、机构客户、投委会 |
| 研究节奏 | 日常跟踪事件，月度更新数据，季度更新业绩，年度写深度，重大变化写专题 |
| 核心能力 | 产业理解、财务建模、估值定价、预期差判断、风险识别、表达能力 |

## 投研部门常见分工

| 分工 | 研究重点 | 典型问题 |
|------|----------|----------|
| 宏观策略组 | 经济周期、政策、利率、汇率、通胀、流动性、资产配置、市场风格 | 当前市场应该配成长、价值、周期还是高股息 |
| 行业研究组 | TMT、消费、医药、新能源、军工、金融、周期等行业和公司 | 哪些公司基本面改善，哪些标的有预期差 |
| 金融工程组 | 量化策略、指数增强、因子、衍生品、ETF、风险模型、交易结构 | 哪些因子有效，组合风险暴露在哪里 |
| 固定收益组 | 利率债、信用债、城投、地产债、可转债、久期、信用利差、违约风险 | 利率方向、信用风险、久期和票息如何配置 |
| 组合研究/配置组 | 把宏观、行业、公司观点落到仓位、行业权重、标的组合 | 哪些行业超配、标配、低配 |
| 数据/专家/合规支持 | 数据库、产业链调研、专家纪要、报告合规审核 | 数据是否可靠，观点是否有底稿和合规依据 |

## 报告类型总览

| 报告类型 | 典型篇幅 | 核心问题 | 适用场景 |
|----------|----------|----------|----------|
| 深度报告 | 20-50 页 | 长期价值和核心逻辑是什么 | 建立大行业、大公司、大主题覆盖 |
| 点评报告 | 1-5 页 | 事件对投资判断有什么影响 | 业绩预告、并购、政策、订单、价格、突发风险 |
| 跟踪报告 | 定期更新 | 原来的假设是否兑现 | 财报季、月度数据更新、核心变量变化 |
| 策略报告 | 不固定 | 市场、行业、主题如何配置 | 年度策略、季度策略、行业比较、风格轮动 |
| 专题报告 | 不固定 | 一个关键问题的深入拆解 | AI 算力景气度、白酒库存周期、锂价下跌影响 |
| 路演材料 | 10-20 页 PPT | 如何高效传播观点 | 投资沟通、客户交流、内部投委会 |

## 深度报告标准流程

| 步骤 | 核心动作 | 产出 |
|------|----------|------|
| 选题 | 判断行业或公司是否有研究价值，优先选空间大、变化大、预期差大、争议大的对象 | 研究对象和选题理由 |
| 提问题 | 明确主问题，例如“行业拐点是否成立”或“公司能否从周期股变成长逻辑” | 主问题和核心假设 |
| 搭框架 | 先写目录和核心结论，再填证据，不先堆资料 | 报告目录和论证链 |
| 收集资料 | 公司公告、财报、招股书、行业数据、竞品资料、专家访谈、产业链价格、政策文件 | 数据底稿 |
| 产业分析 | 需求、供给、价格、成本、库存、产能、技术、渠道、竞争格局 | 行业判断 |
| 公司分析 | 商业模式、产品、客户、成本、壁垒、管理层、资本开支、现金流 | 公司竞争力判断 |
| 财务建模 | 拆收入、毛利率、费用率、利润、现金流、资本开支、营运资本、资产负债表 | 盈利预测模型 |
| 估值定价 | 选择 PE、PB、PS、EV/EBITDA、DCF、SOTP、NAV 等方法 | 目标价和估值区间 |
| 形成结论 | 给出盈利预测、目标价、评级、上涨空间、催化剂、风险点 | 投资建议 |
| 复核推演 | 检查假设是否合理、估值是否双重计算、风险是否足以推翻结论 | 证伪条件和跟踪清单 |

## 公司深度报告框架

| 模块 | 必须回答的问题 |
|------|----------------|
| 投资摘要 | 一句话观点、核心推荐逻辑、盈利预测、目标价、风险是什么 |
| 公司概况 | 历史、股权结构、业务结构、产品结构、收入利润来源是什么 |
| 行业空间 | 市场规模、增速、渗透率、生命周期、天花板在哪里 |
| 商业模式 | 卖什么、卖给谁、怎么赚钱、议价权在哪里、现金流质量如何 |
| 竞争格局 | CR3/CR5、市占率、进入壁垒、替代品、上下游关系如何 |
| 成长逻辑 | 量增、价升、份额提升、品类扩张、区域扩张、海外扩张、效率提升是否成立 |
| 盈利能力 | 毛利率、净利率、ROE、ROIC、费用率、资产周转率如何变化 |
| 财务质量 | 应收账款、存货、经营现金流、资本开支、负债率、商誉、减值风险是否异常 |
| 管理层与治理 | 战略稳定性、激励机制、关联交易、分红、回购、融资历史如何 |
| 估值与目标价 | 相对估值、绝对估值、可比公司、历史估值、情景分析如何支撑目标价 |
| 风险与催化 | 业绩兑现、政策、价格、成本、竞争、汇率、技术路线、订单不及预期等风险是什么 |

## 行业深度报告框架

| 模块 | 必须回答的问题 |
|------|----------------|
| 行业定义 | 产业链边界、上下游、主要产品、盈利环节是什么 |
| 需求端 | 终端场景、客户结构、渗透率、替代逻辑、周期属性如何 |
| 供给端 | 产能、产量、库存、技术路线、进入壁垒、扩产周期如何 |
| 价格机制 | 谁定价，价格跟什么变量走，成本传导能力如何 |
| 利润分配 | 产业链哪一环节赚钱，利润为什么在那里 |
| 竞争格局 | 集中度、龙头优势、区域差异、海外竞争如何 |
| 政策影响 | 补贴、监管、准入、环保、医保、军采、关税如何影响行业 |
| 周期位置 | 行业处于景气上行、见顶、下行、出清还是复苏 |
| 投资主线 | 买龙头、买弹性、买拐点、买低估、买技术变化还是买国产替代 |
| 标的筛选 | 市占率、成本优势、技术壁垒、订单、利润弹性、估值安全边际如何 |

## 点评报告写法

点评报告解决“事件影响”，要求快、准、短，不能写成资料汇编。第一段必须直接给结论：事件利好、利空还是中性，影响多大，是否改变投资逻辑。

| 模块 | 内容 |
|------|------|
| 核心结论 | 事件性质、影响方向、影响幅度、是否改变投资逻辑 |
| 事件描述 | 发生了什么，时间、主体、金额、政策条款、公告口径是什么 |
| 影响拆解 | 影响收入、成本、利润、现金流、估值、竞争格局还是市场情绪 |
| 盈利预测 | 是否上调或下调 EPS、净利润、目标价 |
| 投资建议 | 维持、上调或下调评级，短期催化和风险是什么 |
| 常见场景 | 业绩超预期、订单落地、产品涨价、政策出台、并购重组、处罚、减值、股东减持 |

点评报告必须回答：这个事件对投资判断有什么影响。

## 跟踪报告写法

跟踪报告不是复述财报，而是判断原来的投资逻辑是否还成立。

| 模块 | 内容 |
|------|------|
| 业绩跟踪 | 收入、利润、毛利率、费用率、现金流与预期对比 |
| 经营跟踪 | 销量、价格、库存、订单、开工率、客户、渠道、产能 |
| 假设更新 | 核心变量是否变化，例如价格、销量、成本、汇率、费用 |
| 模型更新 | 调整三张表，更新未来 2-3 年盈利预测 |
| 估值更新 | 根据最新 EPS、行业估值、可比公司变化更新目标价 |
| 结论更新 | 逻辑强化、逻辑削弱、逻辑被证伪、等待验证 |

## 策略报告写法

策略报告解决“市场、行业、主题怎么配”，必须落到配置，不能只做宏观叙述。

| 模块 | 内容 |
|------|------|
| 宏观判断 | 经济增长、通胀、政策、利率、信用、汇率、海外环境 |
| 市场判断 | 估值水平、盈利周期、流动性、风险偏好、资金结构 |
| 风格判断 | 成长/价值、大盘/小盘、高股息/科技、周期/消费 |
| 行业比较 | 景气度、估值、拥挤度、盈利上修、政策催化 |
| 主题投资 | AI、中特估、出海、国产替代、高股息、低空经济等 |
| 组合建议 | 超配、标配、低配行业，推荐标的池，风险提示 |

## 基本面分析框架

| 项目 | 拆解方式 |
|------|----------|
| 收入 | 销量 × 价格；客户数 × ARPU；订单 × 交付；门店数 × 单店收入 |
| 成本 | 原材料、人工、制造费用、折旧、物流、能源、外包成本 |
| 毛利率 | 产品结构、价格、规模效应、成本变化、竞争强度 |
| 费用率 | 销售费用、管理费用、研发费用、财务费用 |
| 利润 | 收入增长、毛利率变化、费用杠杆、税率、少数股东损益 |
| 现金流 | 净利润是否转化为经营现金流，应收、存货、预付是否异常 |
| 资产负债 | 债务压力、短债长投、资本开支、商誉减值、资产周转 |
| 回报率 | ROE = 净利率 × 资产周转率 × 权益乘数；ROIC 看真正经营质量 |

## 盈利预测方法

| 步骤 | 内容 |
|------|------|
| 拆业务 | 每条业务线单独预测收入、毛利率、费用、利润 |
| 收入预测 | 用销量、价格、市占率、产能、订单、门店、客户数等驱动 |
| 毛利预测 | 结合成本、产品结构、规模效应、价格竞争 |
| 费用预测 | 销售、管理、研发费用率随规模变化，不能机械外推 |
| 利润预测 | 至少做未来 3 年，重点是 EPS、净利润、扣非净利润 |
| 三张表联动 | 利润表、资产负债表、现金流量表要逻辑一致 |
| 情景分析 | 乐观、中性、悲观三套假设，对应不同目标价 |
| 敏感性分析 | 价格、销量、毛利率、费用率、估值倍数每变动 1%，利润和目标价怎么变 |

## 估值和目标价

| 方法 | 适用对象 | 目标价逻辑 |
|------|----------|------------|
| PE | 盈利稳定或成长明确公司 | 目标价 = 预测 EPS × 目标 PE |
| PB | 银行、保险、周期底部、重资产公司 | 目标价 = 每股净资产 × 目标 PB |
| PS | 高成长但利润未释放公司 | 目标价 = 每股收入 × 目标 PS |
| EV/EBITDA | 重资产、折旧大、跨国比较公司 | 企业价值与 EBITDA 比较 |
| DCF | 现金流可预测公司 | 未来自由现金流折现 + 永续价值 |
| SOTP | 多业务集团 | 每块业务单独估值后加总，扣除净债务 |
| NAV | 地产、资源、港口、公用事业等资产价值型公司 | 基于资产价值重估 |

目标价不是拍脑袋，必须说明估值倍数来源、可比公司、历史区间、成长性溢价或折价。

## 预期收益计算

目标涨幅：

$$
目标涨幅 = \frac{目标价}{当前价} - 1
$$

总收益：

$$
总收益 = 价格上涨空间 + 股息率
$$

风险收益比：

$$
风险收益比 = \frac{预期上涨空间}{预期下跌空间}
$$

下跌空间来自悲观情景估值、历史低估值、净资产、现金流压力。投资判断不是“公司好”，而是“当前价格是否已经反映了好”。研究的关键是预期差：市场预期 10%，你判断 20%，且证据更强，才有收益来源。

## 从研究员到行业负责人

| 阶段 | 职责 | 核心能力 |
|------|------|----------|
| 初级研究员 | 维护数据、写点评、更新模型、做纪要、跑公司 | 数据整理、财报阅读、执行速度 |
| 成熟研究员 | 独立覆盖 3-5 家公司，写深度、给评级、做盈利预测 | 独立判断、建模、估值、表达 |
| 高级研究员 | 负责行业框架、核心标的、投资主线、重大推荐 | 行业洞察、预期差判断、组合意识 |
| 行业负责人 | 带团队、分配覆盖、统一观点、把行业研究转化为组合建议 | 组织能力、观点一致性、风险控制 |

评价标准：推荐是否赚钱、逻辑是否可验证、报告是否有洞察、模型是否准确、风险是否提前识别。

## 学习路径

| 阶段 | 训练目标 |
|------|----------|
| 第一阶段 | 读财报，能拆收入、成本、利润、现金流 |
| 第二阶段 | 复刻券商研报模型，学会三张表和估值 |
| 第三阶段 | 选一个行业，建立产业链地图和核心数据表 |
| 第四阶段 | 覆盖 3-5 家公司，每家公司建立盈利预测模型 |
| 第五阶段 | 每季度写跟踪，每有事件写点评，每年写 2-3 篇深度 |
| 第六阶段 | 形成自己的投资框架：买点、卖点、催化、风险、仓位建议 |

## 最重要的一句话

投研不是资料整理，而是用证据证明一个可交易的判断。一篇合格研报必须同时回答：为什么现在研究、核心变化是什么、市场错在哪里、利润怎么算、估值怎么算、能赚多少钱、什么情况会错。
