# 投研部门工作流

## 投研部门到底做什么

投研部门的核心任务，是把宏观、行业、公司、财务、估值和市场预期转化为投资判断。最终要回答的问题不是“资料有哪些”，而是：买不买、什么时候买、买多少、预期收益多少、风险在哪里、什么情况证明判断错了。

主要产出包括：

- 深度报告
- 点评报告
- 跟踪报告
- 策略报告
- 数据库
- 盈利预测模型
- 估值模型
- 路演材料
- 晨会纪要
- 组合建议

服务对象包括：基金经理、投资经理、交易员、销售、机构客户和投委会。

## 研究节奏

投研工作通常按照信息频率和决策重要性组织：

- 日常跟踪事件：公告、订单、价格、政策、竞争变化、市场反馈。
- 月度更新数据：销量、库存、排产、价格、开工率、行业景气指标。
- 季度更新业绩：财报、业绩预告、盈利预测、模型假设和目标价。
- 年度写深度：建立行业框架、公司长期逻辑和核心覆盖体系。
- 重大变化写专题：政策、技术路线、供需格局、商业模式发生变化时单独研究。

## 常见分工

| 分工 | 研究重点 | 典型产出 |
|------|----------|----------|
| 宏观策略组 | 经济周期、政策、利率、汇率、通胀、流动性、资产配置、市场风格 | 策略报告、资产配置建议、市场展望 |
| 行业研究组 | TMT、消费、医药、新能源、军工、金融、周期等行业和公司 | 公司深度、行业深度、点评、跟踪 |
| 金融工程组 | 量化策略、指数增强、因子、衍生品、ETF、风险模型、交易结构 | 因子研究、组合优化、风险归因 |
| 固定收益组 | 利率债、信用债、城投、地产债、可转债、久期、信用利差、违约风险 | 债券策略、信用分析、久期建议 |
| 组合研究/配置组 | 把宏观、行业、公司观点落到仓位、行业权重和标的组合 | 组合建议、行业配置、标的池 |
| 数据/专家/合规支持 | 数据库、产业链调研、专家纪要、报告合规审核 | 数据底稿、调研纪要、合规意见 |

## 研究能力核心

优秀投研能力由六类能力构成：

- 产业理解：知道行业如何赚钱，利润在产业链哪里，关键变量是什么。
- 财务建模：能把业务假设转化为收入、利润、现金流和资产负债表。
- 估值定价：能解释目标价来源，而不是只给一个倍数。
- 预期差判断：知道市场已经相信什么，自己和市场差在哪里。
- 风险识别：能提前识别什么变量会推翻结论。
- 表达能力：能把复杂证据压缩成清晰、可交易的判断。

## 标准工作闭环

```text
信息收集 -> 数据清洗 -> 产业验证 -> 财务建模 -> 估值定价 -> 投资结论 -> 跟踪复盘
```

这个闭环的关键是验证。没有来源、没有模型、没有计算、没有置信度的判断，只能算观点，不能算投研结论。
