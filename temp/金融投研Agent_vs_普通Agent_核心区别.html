1. 架构层面的根本差异

▼

普通Agent架构

用户输入 → LLM推理 → 工具调用 → 输出结果

金融投研Agent架构

用户输入 → 意图识别与合规检查 → 任务拆解(投研流程) → 多源数据采集(行情/财报/新闻/研报) → 结构化数据处理(时序/表格/指标计算) → 多维度分析(基本面/技术面/资金面/情绪面) → 逻辑推理与归因(因果链/反事实) → 合规审查(投资建议限制/风险提示) → 输出结构化报告

维度普通Agent金融投研Agent
数据类型文本为主时序数据、结构化表格、非结构化文本、实时行情
数据时效历史数据为主实时/准实时数据至关重要
计算需求文本生成为主数值计算、统计建模、指标推导
准确性要求容忍一定幻觉零容忍数据幻觉
合规约束内容安全即可严格的投资建议限制、风险提示、适当性管理
可解释性可选必须（监管要求、用户信任）
推理链通用推理金融逻辑链（因果→预测→风险→建议）
工具类型通用API金融数据API、计算引擎、回测框架
记忆类型对话记忆市场记忆、历史分析、用户风险画像
错误代价用户体验下降财产损失、合规风险、声誉损害

2. 数据处理层面的差异

▼

金融数据的特殊性

时序性 Financial Time Series

  • 时间戳不可缺失：每条数据必须有明确时间标记
  • 严格时间顺序：数据点间有严格先后关系，不能随意调换
  • 多频率对齐：不同频率数据需对齐（日频/周频/月频/季频），通常采用前向填充法
  • 前视偏差（Look-ahead Bias）：金融分析的致命错误——在分析历史数据时使用了当时不可能获得的信息

结构化程度高

  • 财务报表：严格会计科目体系，资产=负债+所有者权益
  • 行情数据：OHLCV标准格式（Open/High/Low/Close/Volume）
  • 指标数据：预定义计算公式，如ROE=净利率×周转率×杠杆

多源异构

  • 行情数据：交易所实时推送（毫秒级），结构化时序
  • 财务数据：上市公司公告（季报/年报），结构化表格
  • 新闻数据：财经媒体（非结构化文本），需NLP处理
  • 研报数据：券商研究报告（PDF/文本），需解析提取
  • 宏观数据：统计局/央行（月度/季度），低频但重要
  • 另类数据：卫星/舆情/供应链，新兴数据源
数据质量要求极高——以下验证规则任何一条违反都可能是数据错误或造假信号：
  • 会计等式：资产 = 负债 + 所有者权益
  • 利润等式：净利润 = 营业收入 - 营业成本 - 费用 + 其他收益
  • 现金流等式：经营+投资+筹资 = 现金净变动
  • 指标一致性：ROE = 净利率 × 周转率 × 杠杆
  • 非负性校验：货币资金、营业收入、总资产等不应为负

3. 推理层面的差异

▼

金融推理的特殊要求

因果推理 vs 相关推理

金融分析必须区分因果和相关：相关=A和B同时变化（可能巧合）；因果=A的变化导致B的变化。

常见谬误："股价上涨因为成交量放大"→可能是结果而非原因；"ROE高所以是好公司"→可能是高杠杆导致；"行业增长所以公司增长"→不一定，要看市场份额。

因果分析五步法：

  1. 时间先后：A是否先于B发生？
  2. 机制解释：A导致B的传导机制是什么？
  3. 反事实检验：如果A不变，B还会变化吗？
  4. 混淆变量：是否有第三方因素同时影响A和B？
  5. 剂量效应：A的变化幅度是否与B的变化幅度相关？

反事实推理

金融分析经常需要反事实推理："如果利率不降，股市会怎样？""如果茅台提价10%，利润会增长多少？"——需分析变量变化方向/幅度、传导路径、二阶效应、对投资决策的影响。

情景分析

情景概率描述
基准情景（Base Case）约50%最可能发生的情况
乐观情景（Bull Case）约25%利好因素超预期
悲观情景（Bear Case）约25%不利因素超预期

每个情景需明确：核心假设、目标价格、关键驱动因素。

4. 工具层面的差异

▼

普通Agent工具 vs 金融投研Agent工具

普通Agent：网页搜索 / 文件读取 / 代码执行 / 计算器

金融投研Agent需要六大类专业工具体系：

📈 行情数据类

  • 实时行情（价格/盘口）
  • K线数据（历史OHLCV）
  • 逐笔数据（毫秒级明细）
  • 盘口数据（买卖五档）
  • 融资融券（杠杆资金动向）
  • 北向资金（外资流向）

📋 财务数据类

  • 三大报表数据
  • 财务指标（ROE/毛利率等）
  • 分红历史
  • 盈利预测
  • 一致预期（卖方分析师）

🧮 分析计算类

  • 估值模型（DCF/PE/PB）
  • 财务比率计算
  • 回测引擎
  • 技术指标（MA/MACD/RSI）
  • 风险指标（VaR/波动率）
  • 回归分析

📰 新闻研报类

  • 财经新闻检索
  • 券商研报检索
  • 业绩会纪要
  • 监管公告

🌍 宏观数据类

  • 宏观经济数据（GDP/CPI/PMI）
  • 政策日历
  • 经济日历

🛡️ 合规工具类

  • 合规检查（内容审查）
  • 风险提示生成
  • 适当性检查（产品↔投资者匹配）

5. 记忆层面的差异

▼

普通Agent记忆 vs 金融投研Agent记忆

普通Agent：对话历史 + 用户偏好

金融投研Agent需要四类记忆系统：

📊 市场记忆

  • 市场状态（牛市/熊市/震荡）
  • 行业轮动（景气上行行业）
  • 风险溢价水平
  • 市场情绪（恐慌/贪婪）

📝 分析记忆

  • 历史分析结论及依据
  • 预测准确率追踪
  • 模型/策略回测表现

👤 用户记忆

  • 风险画像
  • 投资期限（短/中/长线）
  • 持仓信息
  • 投资偏好（行业/风格）
  • 交互历史

📚 知识记忆

  • 行业知识库（核心指标/分析框架）
  • 估值模型库
  • 风险情景库（历史危机与应对）
  • 监管规则库
