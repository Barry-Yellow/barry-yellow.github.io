估值指标

12 项
市盈率 PE
PE = 市值 / 净利润 = 股价 / 每股收益(EPS)
衡量投资者为每1元净利润愿意支付的价格。PE越高，市场给予的盈利预期越高；PE越低，可能被低估或盈利质量差。需结合行业、增速和历史分位判断。
相对估值盈利稳定公司
市净率 PB
PB = 市值 / 净资产 = 股价 / 每股净资产
衡量股价相对账面价值的倍数。PB < 1 表示市值低于净资产，可能被低估或资产质量差。适用于银行、保险、周期股等资产型公司。
相对估值银行/周期
市销率 PS
PS = 市值 / 营业收入 = 股价 / 每股收入
衡量每1元收入对应的市值。适用于尚未盈利但收入可比的成长型公司，避免净利润为负时PE失效的问题。
相对估值成长公司
企业价值倍数 EV/EBITDA
EV/EBITDA = (市值 + 净债务) / EBITDA
剔除资本结构差异的估值指标，比PE更适合比较杠杆率不同的公司。适用于折旧较重的行业（如电信、公用事业）和跨国比较。
相对估值跨资本结构比较
股息率 Div Yield
股息率 = 每股年度分红 / 当前股价
衡量投资股票每年获得的现金分红回报率。高股息率常见于成熟企业、公用事业和银行，适合追求稳定现金流的投资者。
相对估值高分红/公用事业
市盈增长比率 PEG
PEG = PE / 盈利增速(%)
将PE与盈利增速结合，PEG = 1 表示估值与增速匹配；< 1 可能被低估；> 1 可能高估。弥补PE无法反映增长差异的缺陷。
相对估值成长股
折现现金流模型 DCF
企业价值 = Σ FCFF_t / (1 + WACC)^t + 终值 / (1 + WACC)^n
绝对估值方法，将未来自由现金流折现求和得到企业内在价值。核心假设包括收入增速、利润率、WACC和永续增长率，对假设高度敏感。
绝对估值自由现金流
公司自由现金流 FCFF
FCFF = EBIT × (1 - 税率) + 折旧摊销 - 资本开支 - 营运资本增加
企业在满足再投资需求后可供所有资本提供者（股东和债权人）分配的现金流。是DCF估值的核心输入，反映企业真实造血能力。
绝对估值现金流
股权自由现金流 FCFE
FCFE = 净利润 + 折旧摊销 - 资本开支 - 营运资本增加 + 新增净债务
扣除所有支出和债务变动后，可供股东自由支配的现金流。FCFE直接对应股权价值，比FCFF多了债务现金流的影响。
绝对估值股权价值
加权平均资本成本 WACC
WACC = E/(E+D) × Re + D/(E+D) × Rd × (1 - T)
企业股权和债务资本的加权平均成本，是DCF模型中的折现率。WACC越高，未来现金流的现值越低，估值越保守。利率上升会推高WACC。
折现率资本成本
企业价值 EV
EV = 市值 + 总债务 - 现金及等价物
从收购者角度衡量获取整个企业的成本，比市值更全面地反映资本结构。是EV/EBITDA等指标的基础。
企业价值收购视角
永续增长率 g
终值 = FCFF_(n+1) / (WACC - g)
DCF模型中假设企业长期（永续期）的现金流增长率。通常取2%-3%（接近GDP名义增速），过高会严重高估企业价值。
DCF假设终值

盈利能力指标

10 项
毛利率 Gross Margin
毛利率 = 毛利 / 营业收入 = (收入 - 营业成本) / 收入
反映产品或服务本身的盈利能力，是竞争力的直接体现。高毛利率通常意味着品牌溢价、技术壁垒或成本优势。毛利率下降需警惕价格战或成本上升。
利润表竞争力
净利率 Net Margin
净利率 = 净利润 / 营业收入
衡量每1元收入最终转化为多少净利润，反映整体盈利能力。受毛利率、费用率、投资收益和税率综合影响，是盈利质量的终极指标。
利润表盈利质量
净资产收益率 ROE
ROE = 净利润 / 净资产 = 净利率 × 资产周转率 × 权益乘数
衡量股东投入资本的回报率，是巴菲特最看重的指标。杜邦分解可拆分为净利率（盈利能力）、资产周转率（运营效率）和权益乘数（杠杆水平），揭示ROE驱动力。
杜邦分析股东回报
总资产收益率 ROA
ROA = 净利润 / 总资产
衡量企业运用全部资产创造利润的效率，不受杠杆影响。适合比较不同杠杆水平的公司。ROE高但ROA低可能意味着过度依赖杠杆。
资产效率去杠杆比较
投入资本回报率 ROIC
ROIC = 税后经营利润 / (净资产 + 有息负债)
衡量企业投入全部经营资本的回报效率，剔除非经营资产和超额现金的干扰。ROIC > WACC 说明企业在创造价值，是判断护城河的核心指标。
价值创造护城河
息税前利润 EBIT
EBIT = 净利润 + 所得税 + 利息费用
剔除融资和税负影响的经营利润，反映核心业务盈利能力。便于比较不同资本结构和税率的公司，是EV/EBITDA和FCFF计算的基础。
经营利润跨公司比较
息税折旧摊销前利润 EBITDA
EBITDA = EBIT + 折旧 + 摊销
进一步剔除折旧摊销（非现金支出）的盈利指标，更接近经营现金利润。适用于折旧较重的行业比较，但可能掩盖资本开支的真实压力。
现金利润重折旧行业
每股收益 EPS
EPS = 净利润 / 总股本
每股普通股享有的净利润，是PE计算的分子。需区分基本EPS和稀释EPS（考虑期权、可转债等稀释效应）。EPS增长是股价长期上涨的核心驱动力。
每股指标PE基础
销售费用率 S/G&A Ratio
销售费用率 = 销售费用 / 营业收入
反映渠道投入和获客成本占收入的比重。过高可能意味着获客效率低或竞争激烈；下降则体现规模效应或品牌力增强。
费用率渠道效率
研发费用率 R&D Ratio
研发费用率 = 研发费用 / 营业收入
衡量技术投入强度。高研发费用率常见于科技、医药行业，短期压低利润但可能构建长期壁垒。需关注研发转化效率而非仅看绝对比例。
费用率技术投入

成长性指标

6 项
收入增速 Rev Growth
收入增速 = 本期收入 / 上期收入 - 1
反映需求和市场份额变化，是成长性分析的首要指标。需拆分增长来源：销量增长、价格提升、产品结构升级还是并购并表。
成长性需求
净利润增速 Profit Growth
利润增速 = 本期净利润 / 上期净利润 - 1
反映盈利增长能力。理想情况下利润增速应高于收入增速（经营杠杆），否则需关注毛利率或费用率是否恶化。需区分扣非和含非经常性损益。
成长性盈利增长
复合年均增长率 CAGR
CAGR = (终值 / 初值)^(1/年数) - 1
平滑多年度的增长率，消除单年波动影响。常用于描述收入、利润、行业规模的长期增长趋势。CAGR假设匀速增长，实际波动可能很大。
长期增长平滑波动
每股收益增速 EPS Growth
EPS增速 = 本期EPS / 上期EPS - 1
反映每股盈利的增长速度，考虑了股本稀释的影响。比净利润增速更能反映股东实际回报的增长，是PEG比率的分母。
每股增长PEG基础
渗透率 Penetration
渗透率 = 已采用产品或服务的人数 / 目标市场总人数
衡量产品或技术在目标市场中的普及程度。渗透率10%-50%通常是成长加速期，超过50%增速往往放缓。是判断行业生命周期位置的关键指标。
行业空间成长阶段
市场占有率 Market Share
市占率 = 公司销售额 / 行业总销售额
反映公司在行业中的竞争地位。市占率提升通常意味着竞争优势增强，但市占率高不等于利润高，关键看是否有定价权。
竞争格局行业地位

财务健康指标

8 项
资产负债率 D/A
资产负债率 = 总负债 / 总资产
衡量企业杠杆水平和偿债压力。一般高于70%需警惕，但银行、地产等高杠杆行业属正常水平。需结合有息负债率和利率环境综合判断。
杠杆偿债压力
流动比率 Current Ratio
流动比率 = 流动资产 / 流动负债
衡量企业短期偿债能力。通常2:1为健康水平，低于1意味着短期偿债压力较大。不同行业标准不同，需结合行业特征判断。
短期偿债流动性
速动比率 Quick Ratio
速动比率 = (流动资产 - 存货) / 流动负债
剔除变现能力较差的存货后的短期偿债指标，又称酸性测试比率。1:1为基本健康，低于0.5需关注短期偿债风险。
短期偿债剔除存货
利息保障倍数 ICR
ICR = EBIT / 利息费用
衡量经营利润覆盖利息支出的能力。低于3倍需警惕，低于1.5倍意味着偿债风险较高。利率上行周期中该指标尤为重要。
偿债安全利息覆盖
有息负债率 Int-bearing D/A
有息负债率 = 有息负债 / 总资产
比资产负债率更精准地反映真实杠杆压力，因为只有有息负债才产生利息支出。应付账款等经营性负债不增加利息负担。
真实杠杆利息负担
净债务率 Net D/E
净债务率 = (有息负债 - 现金) / 净资产
考虑现金储备后的真实杠杆水平。净债务率为负意味着现金超过有息负债，财务安全性高。是EV计算和信用分析的核心指标。
净杠杆信用分析
商誉占比 Goodwill %
商誉占比 = 商誉 / 净资产
衡量并购形成的商誉对净资产的侵蚀程度。商誉过高（>30%）存在减值风险，一旦被收购企业业绩不达标，商誉减值将直接冲减利润。
并购风险减值
应收账款周转天数 AR Days
AR Days = 应收账款 / 日均收入 = 应收账款 × 365 / 收入
衡量客户回款速度。天数增加意味着回款变慢、资金占用加大，可能是客户议价权增强或收入质量下降的信号。
回款效率收入质量

现金流指标

6 项
经营现金流净额 OCF
OCF = 经营活动现金流入 - 经营活动现金流出
主业带来的真实现金收入，长期应与净利润匹配。OCF持续低于净利润意味着利润质量差，可能存在应收账款膨胀或收入确认激进等问题。
利润质量现金验证
自由现金流 FCF
FCF = 经营现金流净额 - 资本开支
企业在满足维持和扩张所需投资后可自由支配的现金，是分红、还债和回购的基础。FCF为正且持续增长是优质企业的标志。
估值基础分红能力
现金流质量比 OCF/NP
现金流质量 = 经营现金流净额 / 净利润
衡量利润的现金含量。长期低于0.7需警惕利润虚增；大于1说明利润质量高，现金回收好。是识别财报质量的核心指标。
利润质量财报识别
资本开支 CAPEX
CAPEX = 购建固定资产、无形资产等支付的现金
维持和扩张业务所需的投资支出。重资产企业CAPEX高，FCF压力大；轻资产企业CAPEX低，FCF更充裕。需区分维持性CAPEX和扩张性CAPEX。
投资支出资产轻重
营运资本 WC
营运资本 = 流动资产 - 流动负债 = 应收 + 存货 - 应付
衡量日常经营所需占用的资金。营运资本增加会吞噬现金流，减少则释放现金。负营运资本（如预收款模式）是优质商业模式的特征。
资金占用商业模式
投资/筹资现金流 ICF / FCF_s
ICF = 投资活动现金净额；FCF_s = 筹资活动现金净额
投资现金流反映资本开支和并购（常为负）；筹资现金流反映融资、还债和分红。成长期ICF常为负，成熟期FCF_s常为负（分红还债）。
三表联动生命周期

收益与风险指标

12 项
年化收益率 Ann. Return
年化收益 = (1 + 区间收益)^(365/持有天数) - 1
将不同期限的收益率换算为年度基准，便于横向比较。短期年化可能严重失真，需结合完整市场周期判断。
收益水平横向比较
年化波动率 Ann. Vol
年化波动率 = 日收益率标准差 × √252
衡量收益率的不确定性或风险水平。波动率越高，价格波动越剧烈。是夏普比率、风险预算和VaR计算的基础输入。
风险度量夏普基础
最大回撤 Max DD
Max DD = max((峰值 - 谷值) / 峰值)
净值从历史最高点到后续最低点的最大跌幅，衡量最差持有体验。是投资者实际感受到的极端亏损，也是卡玛比率的分母。
极端风险持有体验
夏普比率 Sharpe
Sharpe = (年化收益 - 无风险利率) / 年化波动率
衡量承担单位波动获得的超额收益，是最常用的风险调整收益指标。Sharpe > 1 优秀，0.5-1 良好，< 0.5 较差。但无法区分上下行波动。
风险调整核心指标
索提诺比率 Sortino
Sortino = (年化收益 - 无风险利率) / 下行波动率
夏普比率的改进版，分母仅用下行波动率（低于目标的波动），不惩罚向上波动。更适合评估不对称收益分布的策略。
下行风险夏普改进
卡玛比率 Calmar
Calmar = 年化收益 / 最大回撤
衡量承担单位最大回撤获得的收益，关注极端亏损而非日常波动。Calmar越高，回撤控制能力越强。适合评估投资者真实体验。
回撤调整持有体验
信息比率 IR
IR = 超额收益 / 跟踪误差 = (组合收益 - 基准收益) / 跟踪误差
衡量主动管理能力，单位跟踪误差获得的超额收益。IR > 0.5 优秀，> 1 极为罕见。是评价基金经理和量化策略的核心指标。
主动管理超额收益
阿尔法 α
α = 组合实际收益 - (无风险利率 + β × 市场风险溢价)
剥离市场Beta后的超额收益，反映基金经理的选股或择时能力。正Alpha意味着跑赢市场风险调整后的预期，是主动管理的终极目标。
超额能力CAPM
贝塔 β
β = Cov(组合收益, 市场收益) / Var(市场收益)
衡量组合对市场涨跌的敏感度。β=1与市场同步，>1放大市场波动，<1缩小市场波动，<0与市场反向。是资产配置和风险预算的基础。
市场敏感系统风险
跟踪误差 TE
TE = 组合收益与基准收益差额的年化标准差
衡量组合与基准的偏离程度。TE越大，主动偏离越多；TE越小，越接近被动跟踪。是信息比率的分母，也是指数增强策略的约束条件。
偏离度主动约束
下行波动率 Downside Vol
下行波动率 = √(Σ min(R_t - R_f, 0)² / N)
仅统计低于目标收益率（通常为无风险利率）的波动，不惩罚向上偏离。比总波动率更贴合投资者对"亏损风险"的感知。
亏损风险索提诺基础
胜率与盈亏比 Win Rate / P-L Ratio
胜率 = 盈利交易次数 / 总交易次数；盈亏比 = 平均盈利 / 平均亏损
胜率衡量交易稳定性，盈亏比衡量单次交易质量。两者组合决定策略期望值：期望 = 胜率 × 盈利 - (1-胜率) × 亏损。高胜率低盈亏比或低胜率高盈亏比均可盈利。
交易质量期望值

量化因子指标

8 项
价值因子 Value
低 PE、低 PB、高股息率、低 EV/EBITDA
买入价格相对基本面便宜的资产。逻辑是市场过度反应导致低估值，长期均值回归带来超额收益。价值陷阱是主要风险：低估值可能因为基本面恶化。
买便宜均值回归
成长因子 Growth
高收入增速、高利润增速、ROE 提升
买入增长强劲的资产。逻辑是高增长公司能持续超越市场预期，推动估值和盈利双升。风险在于增长不达预期时估值回落剧烈（戴维斯双杀）。
买增长戴维斯双杀
质量因子 Quality
高 ROE、高毛利率、高现金流质量、低杠杆
买入基本面优质的资产。逻辑是好公司长期跑赢，因为盈利质量高、抗风险能力强。质量因子在市场下行期通常有防御属性。
买好公司防御属性
动量因子 Momentum
过去 3/6/12 个月收益率（剔除最近1个月）
买入过去表现强势的资产，假设强者恒强。需剔除近1月避免短期反转干扰。风险在于风格切换时回撤大，拥挤交易可能导致踩踏。
强者恒强趋势跟踪
反转因子 Reversal
短期跌幅、超跌程度
买入近期超跌的资产，赌均值回归。与动量因子相反，通常在短期（1个月内）有效。风险在于"接飞刀"：下跌可能因基本面恶化而非过度反应。
均值回归短期有效
波动因子 Volatility
历史波动率、下行波动率
低波动率资产长期风险调整收益优于高波动率资产（低波异象）。逻辑是彩票偏好导致投资者为高波动支付过高溢价。低波因子在防守型策略中常用。
低波异象风险溢价
流动性因子 Liquidity
成交额、换手率、买卖价差
低流动性资产存在流动性风险溢价，长期收益补偿更高。但流动性差的资产在市场恐慌时更难卖出，实际执行成本可能吞噬理论收益。
流动性溢价执行成本
情绪因子 Sentiment
新闻情绪分数、分析师上调/下调、资金流向
捕捉市场预期和情绪变化。情绪极端乐观往往是顶部信号，极端悲观是底部信号。需结合基本面判断情绪是否过度反应。
预期变化逆向信号

基金分析指标

10 项
基金净值 NAV
NAV = 基金资产总值 - 负债 / 总份额
每份基金的价值，是计算收益和回撤的基础。需区分单位净值和累计净值（考虑分红再投资）。净值波动直接反映基金投资表现。
基金基础收益计算
久期 Duration
久期 ≈ 利率变动1%时债券价格变动百分比
衡量债券或债基对利率变动的敏感度。久期越长，利率风险越大。利率上行100bp时，久期5年的债券约跌5%。是固收风险管理的核心指标。
利率风险固收核心
基金杠杆率 Leverage
杠杆率 = 总资产 / 净资产
衡量基金使用杠杆放大投资的程度。杠杆率 > 1 意味着基金通过回购等方式放大了投资。杠杆放大收益也放大亏损，是债基风险的重要来源。
杠杆风险债基
信用下沉比例 Credit Exposure
信用下沉比例 = AA+ 及以下评级债券占比
衡量基金持有低评级信用债的比例，反映信用风险暴露程度。信用下沉可增厚票息收益，但在信用利差扩大或违约时损失更大。
信用风险票息增强
基金换手率 Turnover
换手率 = 调仓规模 / 组合规模
衡量基金调仓频率。高换手率意味着交易频繁，交易成本高，风格可能不稳定。低换手率通常对应长期持有策略。换手率与策略风格应匹配。
交易成本风格稳定性
基金归因分析 Attribution
总超额收益 = 选股贡献 + 行业配置贡献 + 择时贡献 + 交互贡献
拆解基金超额收益来源：来自选股能力、行业配置还是择时。Brinson模型是经典框架。归因分析帮助判断基金经理的真实能力圈。
收益拆解Brinson
风格漂移 Style Drift
通过持仓分析或收益回归检测风格变化
基金经理偏离其宣称的投资风格。如价值基金买入成长股、大盘基金买入小盘股。风格漂移可能导致实际风险与预期不符，影响组合配置效果。
风格一致性风险匹配
定投测算 DCA
定投收益率 = (期末市值 - 累计投入) / 累计投入
定期定额投资通过分散买入时点降低择时风险。定投在先跌后涨的V型市场中效果最好，在持续上涨市场中不如一次性投入。需测算不同情景下的收益和回撤。
择时分散V型最优
穿透持仓分析 Look-through
穿透底层资产，汇总真实行业/个股/风格暴露
通过基金持仓数据穿透到底层股票和债券，识别真实的风险暴露。FOF和组合投资尤其需要穿透分析，避免表面分散但底层集中的问题。
底层暴露FOF
基金费率 Expense Ratio
总费率 = 管理费 + 托管费 + 销售服务费
基金每年收取的费用占净资产的比例。费率直接影响长期收益，1%的费率差异在20年复利下差距显著。指数基金费率通常低于主动基金。
长期成本复利影响

行业分析指标

7 项
行业集中度 CR3 / CR5 / CR10
CRn = 前 n 家企业市场份额之和
衡量行业头部企业的市场份额集中程度。CR > 60% 为高集中度（寡头格局），< 30% 为分散竞争。集中度越高，头部企业定价权越强，利润率越稳定。
竞争格局定价权
行业景气指数 Prosperity Index
景气指数 = 多指标标准化加权（价格、销量、库存、开工率等）
综合反映行业景气方向的指标。景气上行意味着行业量价齐升，企业盈利改善；景气下行则相反。不同行业有不同高频跟踪指标。
景气方向高频跟踪
库存周期指标 Inventory Cycle
库存周期指标 = 库存增速 - 销量增速
判断行业处于被动去库存（复苏）、主动补库存（繁荣）、被动补库存（滞胀）还是主动去库存（衰退）。是周期行业择时的核心工具。
周期择时基钦周期
盈利弹性 Profit Elasticity
盈利弹性 = 行业价格变动1%时公司利润变动幅度
衡量公司利润对行业价格变化的敏感度。高弹性公司在行业景气上行时利润爆发力强，但下行期亏损也大。低弹性公司更稳健但弹性不足。
利润敏感周期弹性
市场空间分层 TAM / SAM / SOM
TAM = 总可用市场；SAM = 可服务市场；SOM = 可获得市场
TAM是行业总需求上限，SAM是企业可触及的细分市场，SOM是实际可获得份额。从TAM到SOM逐步收窄，帮助判断企业真实增长天花板。
市场空间增长天花板
赫芬达尔指数 HHI
HHI = Σ(各企业市占率)²
比CR更精细的行业集中度指标，考虑所有企业份额分布。HHI < 1500 为竞争型，1500-2500 为适度集中，> 2500 为高度集中。常用于反垄断分析。
集中度反垄断
产业链利润分配 Value Chain
各环节利润占比 = 各环节毛利 / 终端售价
分析利润在产业链上下游之间的分配格局。利润通常向壁垒最高的环节集中。识别"微笑曲线"两端（研发和品牌）与中间制造环节的利润差异。
利润分配微笑曲线

宏观与市场环境指标

10 项
国内生产总值 GDP
GDP = C + I + G + (X - M)（消费+投资+政府支出+净出口）
衡量经济总量和增长速度。GDP增速是判断经济周期的核心指标，影响企业盈利、就业和货币政策方向。实际GDP剔除通胀，名义GDP包含通胀。
经济总量周期判断
采购经理人指数 PMI
PMI = 新订单×30% + 生产×25% + 就业×20% + 供应商配送×15% + 库存×10%
50为荣枯线，>50经济扩张，<50经济收缩。PMI是月度发布的领先指标，能快速反映经济景气变化，是资产配置的重要参考。
领先指标荣枯线
消费者物价指数 CPI
CPI = 一篮子商品和服务当期价格 / 基期价格 × 100
衡量居民消费价格水平变化，是通胀最核心的指标。CPI过高引发加息预期（利空股债），CPI过低反映需求不足。核心CPI剔除食品和能源波动。
通胀核心货币政策
生产者物价指数 PPI
PPI = 工业品出厂当期价格 / 基期价格 × 100
衡量工业品出厂价格变化，是CPI的领先指标。PPI上涨可能传导至CPI（成本推动通胀），也可能压缩企业利润（无法传导）。对周期股影响显著。
工业通胀CPI领先
社会融资规模 Total Social Financing
社融 = 人民币贷款 + 委托贷款 + 信托贷款 + 未贴现票据 + 债券 + 股票 + 其他
衡量实体经济从金融体系获得的资金总量，是信用扩张的核心指标。社融放量通常领先经济复苏1-2个季度，是判断流动性环境的关键。
信用扩张流动性
广义货币供应量 M2
M2 = 流通中现金 + 活期存款 + 定期存款 + 其他存款
衡量货币供应总量。M2增速反映货币政策松紧，与社融增速差反映资金在金融体系内还是流入实体。M2高增长通常利好资产价格。
货币供应政策松紧
期限利差 Term Spread
期限利差 = 长期国债收益率 - 短期国债收益率
反映收益率曲线形态。正常为正（长期利率更高）；利差倒挂（短期>长期）是经济衰退的可靠领先信号，也意味着银行盈利承压。
衰退信号收益率曲线
信用利差 Credit Spread
信用利差 = 信用债收益率 - 同期限国债收益率
反映信用风险定价。利差收窄表示市场风险偏好上升、信用环境宽松；利差扩大表示避险情绪升温、违约风险上升。是判断固收投资环境的关键。
信用风险风险偏好
股债收益差 ERP / FED Model
股债收益差 = 盈利收益率(1/PE) - 10年期国债收益率
衡量股票相对债券的吸引力。差值为正且较大时，股票相对便宜；差值为负时，债券更有吸引力。是资产配置中股债比例调整的核心参考。
股债比较资产配置
估值历史分位 Valuation %ile
分位 = 当前PE/PB在历史数据中的百分位排名
衡量当前估值在历史区间中的相对位置。10%分位意味着比历史上90%的时间便宜。需注意：低分位不等于会涨，高分位不等于会跌，但提供了安全边际参考。
历史比较安全边际

交易与策略专有名词

10 项
基差 Basis
基差 = 现货价格 - 期货价格
衡量期货与现货的价格偏离。正基差（现货>期货）为升水，负基差为贴水。基差收敛是期现套利的利润来源，基差变动反映市场预期和供需变化。
期现套利升贴水
冲击成本 Market Impact
冲击成本 = 实际成交均价 - 决策时价格
大额交易对市场价格的影响程度。交易量越大、流动性越差，冲击成本越高。是量化策略从回测到实盘的主要损耗来源，常被忽略导致回测虚高。
交易成本回测失真
滑点 Slippage
滑点 = 实际成交价格 - 预期成交价格
下单到成交之间的价格偏移。高波动和低流动性时滑点更大。滑点与冲击成本共同构成隐性交易成本，是策略实盘表现低于回测的主要原因。
隐性成本执行风险
未来函数 Look-ahead Bias
在t时刻使用了t+1时刻才能获得的数据
回测中最致命的错误，使用了当时不可能知道的信息。如用年报数据在发布前交易、用复权后价格做信号。会导致回测收益虚高，实盘完全失效。
回测陷阱数据对齐
过拟合 Overfitting
模型参数过多，完美拟合历史但无法预测未来
回测中参数过多或过度优化，使策略只适合历史数据。表现为样本内收益极高但样本外大幅衰减。解决方法：样本外测试、参数稳健性检验、简化模型。
回测陷阱参数优化
幸存者偏差 Survivorship Bias
只用当前仍存在的标的做回测，忽略已退市或消失的标的
忽略失败样本导致收益高估。如只回测当前成分股、只分析仍在运作的基金。解决方法：使用包含退市股票的全样本数据库。
回测陷阱样本选择
资本资产定价模型 CAPM
E(R) = Rf + β × (E(Rm) - Rf)
核心资产定价理论：期望收益 = 无风险利率 + Beta × 市场风险溢价。CAPM将收益分解为系统性风险补偿（Beta）和超额收益（Alpha），是现代投资组合理论的基石。
资产定价Alpha/Beta
在险价值 VaR
VaR = 在给定置信水平下的最大可能损失
在给定置信度（如95%）和时间区间下，投资组合可能遭受的最大损失。VaR = 100万（95%）意味着有95%的概率损失不超过100万。缺点是无法描述尾部极端损失。
风险度量尾部风险
净息差 NIM
NIM = (利息收入 - 利息支出) / 生息资产平均余额
银行核心盈利指标，衡量存贷款利差的盈利能力。NIM收窄意味着银行利润承压，通常发生在降息周期。是银行股分析最重要的指标之一。
银行核心利差盈利
再平衡 Rebalance
当资产权重偏离目标超过阈值时，卖出超配、买入低配资产
维持组合目标配置比例的操作。再平衡触发条件包括定期（如季度）和阈值（如偏离5%）。再平衡本质上是纪律性的低买高卖，但会产生交易成本和税务影响。
组合管理纪律调仓
