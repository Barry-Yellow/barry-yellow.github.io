#一、金融投研到底在做什么

#1.1 投研的核心目标

金融投研不是简单判断“涨还是跌”，而是回答四类问题：

问题对应研究内容输出结果
资产是什么股票、债券、基金、商品、外汇、衍生品产品和底层资产画像
为什么会赚钱盈利增长、估值修复、票息、利差、套利、风险溢价收益来源拆解
为什么会亏钱基本面恶化、估值回落、信用违约、流动性冲击、政策变化风险来源拆解
是否适合某个用户风险等级、投资期限、回撤承受能力、现金流需求投顾适配结论

一句话概括：

投研研究“资产是否值得投”，投顾研究“资产是否适合这个人投”。

#1.2 主观研究与量化研究的区别

维度主观研究量化研究
核心方法产业逻辑、公司调研、财报分析、竞争格局、管理层判断数据、模型、因子、回测、统计检验
优势能理解复杂商业变化、政策和非结构化信息可规模化、可回测、纪律性强
劣势主观偏差、难以批量覆盖、验证周期长数据依赖强、容易过拟合、解释有时较弱
典型产出行业深度、公司深度、盈利预测、估值报告因子模型、策略回测、组合优化、风险模型
适合场景个股深度研究、产业趋势判断、重大事件分析多资产配置、选股、择时、风控、基金评价

成熟投研通常不是二选一，而是：

用主观研究形成假设，用量化研究验证假设，用投顾框架匹配用户。

#二、完整投研工作流

#2.1 从问题到结论的标准流程

确定研究问题
  ↓
定义资产和研究范围
  ↓
收集数据：行情、财报、公告、新闻、宏观、行业、持仓、估值
  ↓
建立分析框架：行业、公司、财务、估值、风险、情景
  ↓
形成核心假设：增长、利润率、估值、利率、风险偏好
  ↓
定量测算：收益、回撤、波动、估值、敏感性、情景分析
  ↓
交叉验证：历史、同业、专家观点、市场价格、资金流
  ↓
输出结论：买入/持有/回避/观察，或适配/不适配
  ↓
持续跟踪：财报、政策、价格、预期差、风险事件

#2.2 一份完整投研报告的结构

模块需要回答的问题
核心结论为什么现在研究？结论是什么？主要收益和风险是什么？
行业分析行业空间多大？增长驱动是什么？周期位置在哪里？
公司分析公司靠什么赚钱？护城河在哪里？竞争优势是否可持续？
财务分析收入、利润、现金流、资产负债质量如何？
盈利预测未来收入、利润率、费用率、资本开支如何变化？
估值分析用 PE/PB/EV/EBITDA/DCF/FCFF 是否合理？隐含预期是什么？
催化剂什么事件可能推动价格重估？
风险因素哪些假设错了会导致亏损？
投顾适配适合什么风险等级、期限和目标的用户？

#三、公司基本面研究

#3.1 公司基本面研究的核心问题

研究一家公司，核心不是背指标，而是回答：

  1. 公司卖什么产品或服务。
  2. 谁付钱，为什么愿意付钱。
  3. 公司如何获得收入和利润。
  4. 行业是否还在增长。
  5. 公司相对竞争对手有什么优势。
  6. 这种优势能持续多久。
  7. 未来盈利能否增长，增长质量如何。
  8. 当前价格是否已经反映这些预期。

#3.2 商业模式分析

商业模式关注“公司如何赚钱”。常见维度如下：

维度研究问题示例
客户谁是客户？B 端、C 端还是政府？消费品面向个人，软件可能面向企业
产品产品是否刚需？是否高频？是否可替代？白酒、药品、云服务、汽车
收入模式一次性销售、订阅、佣金、广告、利息、价差？SaaS 订阅、券商佣金、银行净息差
成本结构固定成本高还是变动成本高？制造业原材料成本高，软件边际成本低
定价能力能否涨价？涨价是否影响销量？高端消费品通常定价力更强
规模效应规模扩大后利润率是否提升？平台、软件、半导体设计
现金流先收钱还是先垫钱？预收款模式现金流好，工程类项目回款慢

#商业模式质量判断

高质量商业模式低质量商业模式
高毛利、高复购、高客户粘性低毛利、一次性交易、价格战严重
轻资产、现金流好重资产、高负债、回款慢
有品牌、渠道、技术、网络效应同质化严重、客户议价权强
收入可预测项目制收入波动大

#3.3 竞争格局分析

竞争格局研究“钱最终被谁赚走”。

维度观察指标
市场集中度CR3、CR5、CR10，头部企业市占率
进入壁垒技术、牌照、资本、品牌、渠道、供应链、数据
替代威胁新技术、新商业模式、进口替代、国产替代
供应商议价权原材料集中度、核心部件依赖、上游价格波动
客户议价权大客户占比、客户集中度、转换成本
竞争方式价格战、产品差异化、渠道竞争、服务竞争

常用框架：波特五力模型。

行业内竞争
供应商议价权
客户议价权
潜在进入者威胁
替代品威胁

判断竞争格局时要注意：

  1. 市占率高不等于利润高，关键看是否有定价权。
  2. 行业增长快不等于公司赚钱，可能被价格战吞噬。
  3. 技术领先不等于商业成功，还要看客户、渠道和成本。
  4. 护城河必须能体现到财务指标，例如毛利率、ROE、现金流、客户留存。

#3.4 护城河分析

护城河类型解释财务表现
品牌用户愿意为品牌支付溢价高毛利、稳定销量
成本优势同等产品成本更低毛利率高于同业或价格更具竞争力
网络效应用户越多，产品越有价值用户增长带来边际成本下降
转换成本客户迁移成本高高续费率、低流失率
牌照/资源政策或资源限制进入者稳定利润、竞争者少
技术壁垒专利、工艺、研发积累研发效率、产品领先、毛利稳定

#四、行业研究

#4.1 行业研究的核心问题

行业研究要回答：

  1. 行业空间有多大。
  2. 行业现在处于导入期、成长期、成熟期还是衰退期。
  3. 行业增长来自需求增长、价格上涨、渗透率提升还是政策驱动。
  4. 行业利润在产业链上如何分配。
  5. 当前景气度如何，未来可能上行还是下行。
  6. 哪些公司最受益，哪些公司最受损。

#4.2 行业生命周期

阶段特征投研重点
导入期技术不成熟，需求刚出现，亏损多看技术路线和商业化可能性
成长期需求高速增长，竞争者进入看渗透率、龙头份额、规模效应
成熟期增速放缓，格局稳定看定价权、分红、成本控制
衰退期需求下降，产能过剩看出清、重组、现金流和低估值陷阱

#4.3 产业链分析

产业链分析关注利润如何分配。

上游资源/原材料 → 中游制造/加工 → 下游渠道/品牌/终端客户

例子：新能源汽车产业链。

环节关注点
上游锂、镍、钴资源价格、供需缺口、矿山扩产
中游电池、材料技术路线、成本下降、客户绑定
下游整车品牌、渠道、车型周期、价格战
后市场充电、维修、二手车、保险

#4.4 行业景气度指标

行业常用景气指标
消费零售额、客单价、销量、渠道库存、消费者信心
地产新开工、销售面积、竣工、土地成交、按揭利率
银行信贷增速、净息差、不良率、拨备覆盖率
券商成交额、两融余额、IPO/再融资规模、权益市场表现
半导体库存周期、资本开支、晶圆价格、终端需求
光伏硅料价格、组件价格、装机量、海外需求
医药集采政策、医保支付、研发管线、销售费用率
航运运价指数、船舶供给、港口吞吐、油价

#五、财报解读

#5.1 三张表的关系

报表看什么核心问题
利润表收入、成本、费用、利润公司是否赚钱，利润来自哪里
资产负债表资产、负债、权益公司资产质量和杠杆是否健康
现金流量表经营、投资、筹资现金流公司赚到的是现金还是会计利润

三张表的逻辑：

利润表：这一期赚了多少钱
资产负债表：期末还剩下什么资产和负债
现金流量表：这一期现金怎么流入和流出

#5.2 利润表分析

指标公式含义
收入增速本期收入 / 上期收入 - 1需求和市场份额变化
毛利率毛利 / 收入产品竞争力和成本控制
销售费用率销售费用 / 收入渠道投入和获客成本
管理费用率管理费用 / 收入管理效率
研发费用率研发费用 / 收入技术投入强度
净利率净利润 / 收入最终盈利能力

利润表分析顺序：

  1. 收入是否增长。
  2. 增长来自销量、价格、产品结构还是并表。
  3. 毛利率是否提升或下降。
  4. 期间费用是否被规模效应摊薄。
  5. 利润增长是否高于收入增长。
  6. 扣非净利润是否与净利润一致。

#5.3 资产负债表分析

科目重点问题风险信号
货币资金现金是否充足账上现金多但有大量短债
应收账款客户是否及时付款应收增速远高于收入增速
存货产品是否卖得出去存货大增、跌价准备不足
固定资产是否重资产扩张产能过剩、折旧压力大
商誉并购是否有效商誉大且业绩承诺不达标
短期借款短期偿债压力短债长投、流动性紧张
有息负债杠杆水平利息费用侵蚀利润

#5.4 现金流分析

指标含义判断
经营现金流净额主业带来的现金长期应与净利润匹配
投资现金流净额资本开支、并购、理财成长期常为负，需看回报
筹资现金流净额借钱、还钱、分红、增发判断资金来源
自由现金流企业可自由支配现金估值和分红能力基础

自由现金流常用简化公式：

FCF = 经营现金流净额 - 资本开支
FCFF = EBIT × (1 - 税率) + 折旧摊销 - 资本开支 - 营运资本增加
FCFE = 净利润 + 折旧摊销 - 资本开支 - 营运资本增加 + 新增净债务

#5.5 财报质量识别

重点风险信号：

  1. 收入增长很快，但经营现金流长期为负。
  2. 应收账款增速显著高于收入增速。
  3. 存货大幅增加，同时毛利率下降。
  4. 非经常性损益贡献大量利润。
  5. 商誉过高，存在减值风险。
  6. 关联交易占比高。
  7. 大股东质押比例高。
  8. 审计意见异常或频繁更换审计机构。

#六、盈利预测

#6.1 盈利预测的基本思路

盈利预测不是拍脑袋给利润增速，而是拆分驱动因素。

收入 = 销量 × 价格
毛利 = 收入 × 毛利率
营业利润 = 毛利 - 销售费用 - 管理费用 - 研发费用 - 财务费用
净利润 = 营业利润 + 投资收益 + 其他收益 - 所得税 - 少数股东损益

#6.2 收入预测方法

方法适用场景示例
量价拆分制造、消费、资源品销量增长 10%，价格下降 3%
门店/客户数 × 单店/客单价连锁、互联网、消费门店数、同店增长、客单价

#七、估值方法

#7.1 相对估值

相对估值用同类公司或历史估值对比当前价格是否合理。

方法公式适用对象
PE市值 / 净利润盈利稳定的公司
PB市值 / 净资产银行、保险、周期、资产型公司
PS市值 / 收入尚未盈利但收入可比的成长公司
EV/EBITDA企业价值 / EBITDA资本结构不同、折旧较重行业
股息率每股分红 / 股价高分红、公用事业、成熟企业

相对估值的关键不是“低 PE 就便宜”，而是：

估值 = 增长质量 + 盈利稳定性 + 竞争壁垒 + 利率环境 + 风险偏好

#7.2 DCF 与自由现金流模型

DCF 的核心思想：企业价值等于未来自由现金流折现之和。

企业价值 = Σ FCFF_t / (1 + WACC)^t + 终值 / (1 + WACC)^n
终值 = FCFF_(n+1) / (WACC - 永续增长率)
股权价值 = 企业价值 - 净债务
每股价值 = 股权价值 / 总股本

#DCF 的关键假设

假设含义风险
收入增速未来增长速度过度乐观会高估价值
利润率未来盈利能力竞争加剧会压低利润率
资本开支维持和扩张所需投入重资产企业 FCF 压力大
营运资本应收、存货、应付变化回款恶化会吞噬现金
WACC加权资本成本利率上升会压低估值
永续增长率长期增长假设不能长期高于经济增速太多

#7.3 估值中最常见的错误

  1. 只看 PE，不看利润质量。
  2. 用周期高点利润算低估。
  3. 对成长股给过高永续增长率。
  4. 忽略股权稀释和净债务。
  5. 忽略资本开支，利润高但自由现金流差。
  6. 用不可比公司做可比估值。

#九、量化研究基础

#9.1 量化研究在做什么

量化研究用数据和模型寻找可重复的收益来源。核心步骤：

提出假设 → 构造指标/因子 → 数据清洗 → 回测 → 风险评估 → 组合构建 → 实盘跟踪

#9.2 常见量化因子

因子类型代表指标逻辑
价值PE、PB、股息率、EV/EBITDA买便宜资产
成长收入增速、利润增速、ROE 提升买增长资产
质量ROE、毛利率、现金流质量、低杠杆买好公司
动量过去 1/3/6/12 月收益强者恒强
反转短期跌幅、超跌程度均值回归
波动历史波动率、下行波动率风险补偿或低波异象
流动性成交额、换手率、买卖价差流动性风险溢价
情绪新闻情绪、分析师上调、资金流预期变化

#9.3 回测关键指标

指标公式/含义用途
年化收益将区间收益换算成年化收益水平
年化波动收益率标准差年化波动风险
最大回撤净值从高点到低点最大跌幅极端亏损体验
夏普比率(年化收益 - 无风险利率) / 年化波动单位波动收益
卡玛比率年化收益 / 最大回撤回撤调整后收益

#9.4 回测容易犯的错误

  1. 未来函数：用了当时还不知道的数据。
  2. 幸存者偏差：只用当前仍上市或仍存在的标的。
  3. 过拟合：参数过多，只适合历史。
  4. 忽略交易成本、冲击成本和滑点。
  5. 忽略流动性，策略容量不现实。
  6. 样本期太短，只覆盖一种市场环境。
  7. 只看收益，不看回撤、波动和持有体验。

#十、常见投资策略

#10.1 全天候策略

全天候策略的核心是：不同经济环境中配置不同资产，让组合不过度依赖单一宏观情景。

宏观环境常见受益资产
经济增长上行，通胀温和股票、信用债
经济增长下行，通胀下行长久期利率债
通胀上行，增长稳定商品、资源股、通胀挂钩资产
滞胀黄金、商品、部分防御资产

全天候不是永远赚钱，而是通过多资产分散降低单一场景暴露。

#10.2 动量策略

动量策略假设：过去表现强的资产未来一段时间可能继续强。

常见做法：

  1. 计算过去 3、6、12 个月收益率。
  2. 剔除最近 1 个月，减少短期反转影响。
  3. 排名选择强势资产。
  4. 定期调仓。
  5. 加入止损、波动率控制和行业约束。

风险：

  1. 市场风格切换时容易大回撤。
  2. 拥挤交易可能导致踩踏。
  3. 高换手会放大交易成本。

#10.3 价差策略

价差策略关注两个相关资产之间的价格偏离。

常见类型：

类型例子逻辑
配对交易同行业两只股票价差偏离后回归
期现套利期货与现货基差收敛
跨期套利不同到期月份期货期限结构回归
跨市场套利A/H 股、ETF 一二级市场同一资产不同市场价差
可转债套利转债、正股、期权价值债底 + 转股价值错配

关键风险：相关性失效、流动性不足、交易成本、强制平仓、制度限制。

#10.4 套息交易

套息交易通常是借入低利率货币或低成本资金，买入高收益资产，赚取利差。

收益来源 = 高收益资产收益 - 融资成本 - 汇率/价格波动损失

例子：

  1. 外汇套息：借低利率货币，买高利率货币资产。
  2. 债券套息：融资买入收益率更高的债券。
  3. 杠杆票息策略：通过杠杆放大票息收益。

主要风险：汇率反向波动、利率上行、信用利差扩大、融资收紧、流动性冲击。

#10.5 固收、固收+、权益类策略

类型主要资产收益来源风险来源适合用户
纯固收国债、金融债、信用债、存单票息、久期、信用利差利率、信用、流动性低风险、稳健型
固收+债券 + 少量股票/转债/打新/量化票息 + 权益增强权益回撤、转债波动稳健偏进取
权益类股票、股票基金、ETF企业盈利增长、估值提升市场波动、行业风险中高风险、长期资金
多资产股债商金等分散化、再平衡相关性上升、模型失效追求长期稳健配置

#10.6 策略评价框架

评价策略不能只看收益，要看：

  1. 收益来自哪里：风险溢价、阿尔法、杠杆、流动性、运气。
  2. 最大可能亏多少：最大回撤、压力测试。
  3. 什么时候失效：市场环境、拥挤度、政策变化。
  4. 能投多少钱：容量和流动性。
  5. 是否可持续：逻辑是否长期存在。
  6. 是否适合用户：风险等级和持有期限是否匹配。

#十一、基金产品量化测算与分析

#11.1 基金分析的核心问题

分析一只基金，不是只看过去收益，而是回答：

  1. 基金投什么资产。
  2. 收益来自市场 beta、行业暴露、风格暴露还是基金经理 alpha。
  3. 风险有多大，最大回撤是否能承受。
  4. 和同类产品相比是否有优势。
  5. 基金经理风格是否稳定。
  6. 当前是否适合用户的风险承受能力和投资期限。

#11.2 基金产品画像

维度分析内容
产品类型货币、债券、混合、股票、指数、FOF、QDII
投资范围股票仓位、债券仓位、可转债、港股、商品、衍生品
基准沪深 300、中证 800、偏股基金指数、中债指数等
规模规模过小有清盘风险，过大可能影响操作灵活性
费率管理费、托管费、销售服务费、申赎费
基金经理任职年限、历史业绩、风格稳定性
持仓行业集中度、前十大重仓、换手率

#11.3 基金收益风险测算

常用输入：基金净值序列、同类基金指数、业绩比较基准、无风险利率。

指标解读
区间收益过去一段时间赚了多少
年化收益收益年化，便于比较
年化波动率净值波动程度
最大回撤最差持有体验
夏普比率承担单位波动获得的超额收益
信息比率相对基准的超额收益稳定性
Alpha超越市场和风格暴露后的能力
Beta对市场涨跌的敏感度
跟踪误差与基准偏离程度
下行波动只统计亏损方向波动
Calmar年化收益 / 最大回撤

#11.4 基金归因分析

基金收益可以拆成：

基金收益 = 市场 beta + 行业配置 + 风格暴露 + 个股选择 + 择时 + 交易成本 + 运气

常见归因维度：

归因类型看什么
资产配置归因股票、债券、现金、商品比例是否贡献收益
行业归因超配或低配哪些行业
个股归因重仓股选择是否有效
风格归因偏成长、价值、大盘、小盘、质量、动量
择时归因是否在市场上涨前加仓、下跌前减仓

#11.5 基金定投测算

定投测算要关注：

  1. 定投频率：周、双周、月。
  2. 每期金额。
  3. 投资期限。
  4. 退出规则：目标止盈、估值止盈、再平衡、持有到期。
  5. 最大浮亏和回本时间。

定投收益的核心不是“每次买低”，而是用纪律性平滑买入成本，适合波动较高但长期有正期望的资产。

#11.6 一只基金的分析报告模板

模块内容

基金画像类型、规模、费率、经理、投资范围
业绩表现近 1/3/5 年收益，同类排名，基准比较
风险指标波动、回撤、下行风险、极端月份
风格分析成长/价值、大盘/小盘、行业集中度
持仓分析重仓股、债券久期、信用等级、换手率
归因分析收益来自市场、行业、个股还是择时
情景分析牛市、熊市、震荡市、利率上行下表现

#十二、资产配置与投顾

#12.1 投顾和投研的连接

投研给出资产观点，投顾要把观点转换为用户可执行方案。

投研观点：权益资产长期预期收益较高，但短期波动较大
投顾转换：适合风险承受能力较高、资金期限 3 年以上的用户；不适合作为短期备用金配置

#12.2 用户画像

维度需要了解什么
风险承受能力能否承受本金波动和最大亏损
投资期限3 个月、1 年、3 年、5 年以上
流动性需求是否随时可能用钱
收益目标保值、稳健增值、长期增长
投资经验是否理解基金、股票、债券风险
资产负债收入稳定性、负债压力、备用金
行为特征是否容易追涨杀跌、恐慌赎回

#12.3 组合构建流程

用户画像 → 风险等级 → 目标收益和最大回撤约束 → 资产类别选择 → 产品筛选 → 权重配置 → 再平衡 → 持续陪伴

#12.4 常见组合类型

组合资产结构目标
保守型货币 + 短债 + 高等级债控制波动和流动性
稳健型债券为主 + 少量权益/转债追求稳健增强
平衡型股债均衡中长期增值
进取型权益为主 + 少量债券长期高收益，承受较大回撤
全天候型股票、债券、黄金、商品、现金多场景分散

#12.5 再平衡

再平衡是把组合权重拉回目标比例。

例子：目标为 60% 股票、40% 债券。股票上涨后变成 70%，债券变成 30%，再平衡会卖出部分股票、买入债券。

再平衡的作用：

  1. 控制风险暴露。
  2. 强制低买高卖。
  3. 避免组合漂移到不适合用户的风险等级。

#十三、不同资产类别研究重点

#13.1 权益类

权益类研究重点：

  1. 企业盈利增长。
  2. 商业模式和竞争壁垒。
  3. 行业景气和政策。
  4. 估值水平和市场风险偏好。
  5. 资金流和风格切换。

适合长期资金，但短期波动较大。

#13.2 固收类

固收类研究重点：

维度内容
利率风险久期越长，对利率越敏感
信用风险发行人是否可能违约
流动性风险能否顺利买卖
期限利差长短期限收益率差
信用利差信用债相对利率债的补偿
杠杆风险回购融资放大收益和风险

固收不是无风险。债券基金也可能因为利率上行、信用事件、赎回冲击而亏损。

#13.3 固收+

固收+ 的关键是“+”的部分加了什么。

增强来源风险
股票权益市场回撤
可转债股性波动、溢价率压缩
打新政策变化、收益下降
量化对冲模型失效、基差风险
高收益债信用风险

分析固收+ 产品时，要看权益仓位上限、转债仓位、历史最大回撤和极端市场表现。

#13.4 商品和黄金

商品研究关注供需、库存、产能、地缘政治、美元和实际利率。黄金通常与实际利率、美元、避险需求相关。

#十四、宏观与市场环境分析

#14.1 宏观四象限

环境特征资产表现倾向
复苏增长上行、通胀低位股票、信用债较好
过热增长上行、通胀上行商品较好，债券承压
滞胀增长下行、通胀上行股票债券都承压，商品/黄金可能防御

变量影响路径
利率影响债券价格、股票估值、融资成本
通胀影响企业成本、居民购买力、货币政策
汇率影响出口、进口成本、外资流动
信用影响企业融资和经济扩张
政策影响行业景气和风险偏好
流动性影响估值和市场交易拥挤度

#十五、从研究到投资建议的合规表达

#15.1 投研结论和投顾建议的区别

类型可以表达需要避免
投研结论某资产的收益来源、风险、估值、情景分析绝对化预测、保证收益
投顾建议基于用户画像的适配性说明未了解用户就给具体买卖指令
教育内容解释概念、方法、风险暗示稳赚、诱导交易

#15.2 合规表达模板

更稳妥的表达：

该产品历史波动较高，适合风险承受能力较强、投资期限较长的用户。
如果用户资金用途较短或无法承受净值回撤，应谨慎配置或降低比例。
历史业绩不代表未来表现，具体配置需结合个人风险测评和资产状况。

不应表达：

这只基金一定会涨。
现在必须买入。
保证收益。
亏了我负责。

#十六、投研系统或金融 Agent 如何落地

#16.1 投研 Agent 的能力模块

模块功能
数据接入行情、财报、公告、新闻、基金净值、宏观数据
信息抽取公司、行业、事件、财务指标、风险点识别
研究框架行业、公司、财务、估值、策略模板
计算工具收益风险、估值、DCF、基金测算、回测
证据管理每个结论绑定数据来源和引用
反思校验检查未来函数、数据缺失、结论跳跃、合规风险
用户适配根据风险等级和期限转为投顾表达
追踪监控研究对象后续公告、新闻、价格和风险事件

#16.2 一个 Agent 工作流示例：分析一只基金

用户问题：这只基金怎么样，适合我买吗？

1. 识别基金代码和产品类型
2. 拉取基金净值、规模、费率、持仓、基金经理信息
3. 计算收益、波动、最大回撤、夏普、同类排名
4. 分析持仓行业、风格和集中度
5. 对比同类基金和业绩基准
6. 判断收益来源和风险来源
7. 结合用户风险等级、期限、资金用途做适配判断
8. 输出合规结论和风险提示

#16.3 一个 Agent 工作流示例：分析一家公司

用户问题：某公司基本面如何？

1. 拉取公司基本信息、主营业务、财报、公告、新闻
2. 识别行业和产业链位置
3. 分析商业模式、竞争格局、护城河
4. 解读三张财务报表和核心财务指标
5. 建立收入、利润、现金流预测
6. 使用 PE/PB/EV/EBITDA/DCF 做估值区间
7. 提取催化剂和风险因素
8. 输出结论、证据、假设、风险和待跟踪事项

#16.4 一个 Agent 工作流示例：宏观环境判断与资产配置

用户问题：现在市场环境下，我的资产应该怎么配置？

需要数据：宏观数据（GDP、PMI、CPI、PPI、社融、信贷）、
利率与利差数据（国债收益率曲线、期限利差、信用利差）、
主要资产估值分位与股债收益差、用户风险等级与投资期限

处理流程：判断经济增长方向（PMI、社融是否改善）→
判断通胀与流动性方向 → 映射到复苏/过热/滞胀/衰退四象限 →
结合估值分位和用户画像，生成保守/稳健/平衡/进取配置方案

计算指标：股债收益差 = 盈利收益率 - 10年国债收益率、
估值历史分位数、期限利差与信用利差、
组合预期收益与最大回撤情景测算

结果输出：当前宏观状态判断、大类资产高配/标配/低配观点、
推荐权重区间而非单一比例、主要风险与最短持有期限

#16.5 一个 Agent 工作流示例：行业景气度跟踪

用户问题：这个行业现在景气度怎么样，哪些公司更受益？

需要数据：行业高频数据（价格、销量、库存、开工率、订单）、
产业链上下游数据（原材料价格、中游利润、下游需求）、
行业内公司收入增速、毛利率、存货、产能与市占率

处理流程：识别行业生命周期 → 拆分需求驱动因素 →
跟踪景气指标变化（价格、库存、订单是否改善）→
对比公司成本优势与产能弹性，判断谁最受益

计算指标：行业景气指数（多指标标准化加权）、
库存周期指标 = 库存增速 - 销量增速、
盈利弹性 = 行业价格变动1%时公司利润变动幅度、市占率变化

结果输出：景气方向判断（上行/下行/底部修复/顶部回落）、
受益环节与公司类型、后续需跟踪的验证指标与风险提示

#16.6 一个 Agent 工作流示例：分析固收或债券基金

用户问题：这只债券基金稳不稳，会不会亏很多？

需要数据：基金净值、规模、费率与历史持仓、
债券久期、评级、券种与行业分布、
国债收益率曲线与信用利差、机构持有人比例

处理流程：判断产品类型（短债/纯债/二级债基）→
拆解收益来源（票息/久期/信用下沉/杠杆）→
分析极端情景（利率上行、信用利差扩大、大额赎回）

计算指标：年化收益与最大回撤、夏普与卡玛比率、
久期风险 = 利率上行100bp时估算净值损失、
信用下沉比例（AA+以下占比）、杠杆水平 = 总资产/净资产

结果输出：产品风险等级、收益来源解释、
极端情景测算与同类比较、适合的投顾场景与风险提示

#16.7 一个 Agent 工作流示例：拆解固收+产品

用户问题：这只固收+基金为什么波动比纯债大，它的"+"到底加了什么？

需要数据：基金净值与资产配置比例（债券/股票/转债/现金）、
债券持仓久期与评级、权益与转债仓位及行业分布、
债券指数、权益指数、转债指数用于回归分析

处理流程：确认产品定位（稳健/平衡/权益增强型）→
拆分底仓收益（票息/久期）与增强收益（股票/转债/打新）→
检查极端市场表现（股跌债涨、股债双杀、转债杀估值）

计算指标：权益与转债仓位均值及峰值、
增强收益贡献 = 基金收益 - 债券基准收益、
最大回撤阶段由哪类资产引起、对各类指数的Beta暴露

结果输出：固收部分是否稳健、"+"的具体来源与占比、
增强是否有效匹配风险、适合用户类型与建议持有期限

#16.8 一个 Agent 工作流示例：构建基金组合与再平衡

用户问题：我想买几只基金组成组合，应该怎么搭配？后续怎么调仓？

需要数据：用户风险等级与期限、候选基金收益/风险/相关性、资产类别指数、约束条件（权重上限/合规限制）
处理流程：用户画像映射组合目标 → 确定大类权重 → 筛选基金并优化分配 → 设计再平衡规则（定期或偏离阈值触发）
计算指标：组合预期收益/波动/回撤/夏普、资产权重与集中度、压力测试损失、再平衡触发条件
结果输出：组合定位与推荐权重、收益风险预期（三种情景）、再平衡规则、投顾适配与风险提示

#16.9 一个 Agent 工作流示例：用户持仓诊断与投顾适配

用户问题：我现在持有这些基金和股票，风险大不大，要不要调整？

需要数据：用户全部持仓与成本、用户风险画像、基金穿透持仓（行业/风格/仓位）、市场估值与波动数据
处理流程：汇总资产结构 → 穿透底层识别真实行业与个股集中度 → 检查与用户风险等级是否匹配 → 生成调整建议
计算指标：权益穿透仓位、行业/重仓集中度、组合历史回撤、与建议权益仓位差额、调仓成本
结果输出：账户诊断结论（过度集中/风格单一/风险超标）、调整建议与执行顺序、合规适配表达

#16.10 一个 Agent 工作流示例：动量轮动策略回测

用户问题：能不能用动量策略在几个指数之间轮动？历史效果怎么样？

需要数据：标的池历史价格/净值、成交额与流动性、基准指数、无风险利率、交易费率与约束条件
处理流程：定义标的池与样本期 → 构造动量因子（剔除近1月）→ 按排名选标并设定权重 → 扣除成本回测 → 参数稳健性检验
计算指标：年化收益/波动/回撤/夏普、超额收益与信息比率、换手率与交易成本占比、分市场环境表现
结果输出：策略是否稳定有效、收益来源、风险约束规则、实盘可行性与投顾适配表达

#16.11 一个 Agent 工作流示例：新闻公告事件驱动分析

用户问题：这条新闻或公告对公司/行业/基金有什么影响？

需要数据：原始文本（公告/新闻/政策）、相关标的价格与成交量、公司基本面结构、历史类似事件库
处理流程：识别事件主体与类型 → 判断信息可信度 → 建立影响路径（收入/成本/估值/风险偏好）→ 对照历史类似事件
计算指标：事件情绪分数、组合中相关资产穿透占比、历史事件平均超额收益、盈利敏感性
结果输出：利好/利空/中性/待验证结论、影响层级（短期情绪/中期盈利/长期格局）、后续跟踪指标

#十七、实战学习路径

#17.1 第一阶段：金融基础

学习重点：

  1. 股票、债券、基金、ETF、可转债、商品、外汇基础。
  2. 三张财务报表。
  3. PE、PB、ROE、毛利率、现金流等指标。
  4. 基金净值、收益、波动、回撤。

练习：选择 3 只不同类型基金，计算过去 1 年收益、波动和最大回撤。

#17.2 第二阶段：主观投研

学习重点：

  1. 行业生命周期。
  2. 商业模式分析。
  3. 竞争格局和护城河。
  4. 盈利预测和估值。

练习：选择一家上市公司，写一页纸基本面分析。

#17.3 第三阶段：量化研究

学习重点：

  1. 收益率、波动率、回撤、夏普。
  2. 因子和回测。
  3. 动量、反转、价值、质量策略。
  4. 交易成本和过拟合。

练习：用指数 ETF 做简单动量轮动回测。

#17.4 第四阶段：资产配置与投顾

学习重点：

  1. 用户风险画像。
  2. 股债配置和再平衡。
  3. 全天候、多资产组合。
  4. 合规表达和适当性。

练习：为保守、稳健、进取三类用户设计基金组合，并说明原因。

#十九、一个完整案例框架

#19.1 分析一家公司

研究对象：某消费龙头公司

1. 行业：消费行业增速放缓，但高端化趋势仍在。
2. 商业模式：品牌溢价 + 渠道掌控 + 高毛利。
3. 竞争格局：头部集中，二三线品牌竞争更激烈。
4. 财务：收入稳定增长，毛利率较高，经营现金流优于净利润。
5. 盈利预测：销量低个位数增长，价格和产品结构贡献中个位数增长。
6. 估值：PE 高于历史均值，需要增长兑现支撑。
7. 催化剂：旺季销售超预期、渠道库存下降、分红提升。
8. 风险：消费疲软、渠道压货、价格体系松动。
9. 结论：公司质量较高，但需关注估值安全边际和需求趋势。

#19.2 分析一只固收+基金

研究对象：某固收+基金

1. 产品类型：债券为底仓，少量权益和可转债增强。
2. 收益来源：票息收益 + 久期管理 + 权益增强 + 转债弹性。
3. 风险来源：利率上行、信用利差扩大、权益市场下跌、转债估值压缩。
4. 历史表现：年化收益中等，最大回撤高于纯债基金但低于偏股基金。
5. 持仓分析：债券信用等级、久期、转债仓位、权益行业暴露。
6. 同类比较：看收益排名、回撤排名、夏普、卡玛、规模和费率。
7. 适配结论：适合能承受一定净值波动、期限 1 年以上、追求稳健增强的用户。

#二十、最终总结

金融投研可以理解为三层能力：

层级核心能力典型问题
资产研究看懂股票、债券、基金、行业和策略这个资产为什么涨跌？
定量测算用数据计算收益、风险、估值和情景赚多少、亏多少、概率如何？
投顾适配把研究结论转成用户可理解、可执行、合规的建议是否适合这个用户？

最重要的学习方法是：

  1. 每研究一个资产，都拆分收益来源和风险来源。
  2. 每看到一个结论，都追问证据和假设。
  3. 每做一个测算，都检查数据、成本、回撤和极端情景。
  4. 每输出一个建议，都回到用户画像和合规边界。

一句话收束：

好的金融投研不是预测未来，而是在不确定性中建立可解释、可验证、可跟踪、可风控的决策框架。
